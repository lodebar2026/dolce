# 排版：「展开 / 原样」两档

**判据全录** → 无单独实现篇；两档共用的简谱引擎见 [排版-简谱引擎.md](排版-简谱引擎.md)

## 职责

**两档的唯一语义是「排版方式」**，不是版式主题、也不是文档格式的分支：

| 档 | 语义 | 用途 |
|---|---|---|
| **展开** | 反复与多段歌词**逐遍展开**，一段歌词一遍谱、逐遍成页 | 投影（一屏一段） |
| **原样** | 按原谱排一遍，多段歌词叠在同一条谱行下、反复不展开 | 印刷歌本 |

**各格式两档语义一致**，同一个简谱引擎（`layout/jianpu/`）、同一把尺子；公共那一半（逐遍走演唱顺序、分页）在 `src/jianpu/`。
纸张、字号、配色**不属于这两档的分野**——它们是独立设置项，两档各记各的一套。

## 入口

| 文件 | 作用 |
|---|---|
| `src/jianpu/profile.ts` | 档位 `JianpuLayoutMode = "expanded"\|"original"`；`jpProfile`/`originalProfile` 是两档各记的档名 |
| `src/layout/jianpu/compose/index.ts::layoutJianpu` | 引擎入口；展开档开 `expanded`（`ScorePainter` 收到 `view: "expanded"` 的请求时） |
| `src/layout/jianpu/place/expand.ts` | **展开档**：按 `PlayItem[]` 从行视图切小节、逐遍接成一长行、逐行装满，拼成「展开后的」行视图交给 `layoutSong` |
| `src/jianpu/vertical.ts` | 纵向分页 `paginate`（只认块的占位盒） |
| `src/jianpu/expand.ts` | `walkPlay` 按 `PlayItem[]` 逐遍逐小节回调 |

## 关键判据

- **展开档**（`place/expand.ts`）：
  - 一份多首（文本谱 `-----`）逐首排、各按自己的演唱顺序（推不出的那首照原样）；每首只排带歌词的那个声部（同 `jianpuInputOfDoc` 的 `forExpanded`）；小节切法同 `jianpu/phrasesong.ts::buildMeasures`（演唱顺序的 `mid` 按它数）；
  - 每遍只挂段号区间罩住本遍遍号的那行词，同号歌词顺延（`distinctVerses`）；音符身份带 `pass`（是段号，不是第几遍）；
    某段整首最后一个字之后的音（副歌只写在第 1 段：190《凡愿意者可来》、020《向主歌唱》第 2 遍的哈利路亚）借最前面在这一格写了字的那段，
    段中间 `/` 留空的拖腔格后面还有本段的字、不借（`afterVerseEnd`；用户定 2026-10-14）；
  - 只要旋律与词：和弦、段落词、奏法、力度/术语、小节线上的跳转字、松叶、临时伴奏都不画，延长记号、倚音与上下滑音留着（倚音、滑音用户定保留）；房号不画；
    唱了不止一遍的小节反复线画成普通线；`.jpwabc` 小节线一律细线、整首最后一条画终止线，其余格式照源、整首末条细线补成终止线；
    **终止线只画在整首最后**：D.C. 前、曲中 `|]` 唱到半路的都画成细线（用户定 2026-10-14）；
  - 断行：源里的换行照断（`.jpwabc` 断在行末那个符号后、其余格式断在那个小节末），换页照源（文本谱 `[fenye]`、123/ABC 的 `$$`、ABC 的 `%%newpage`、`.jpwabc` 模型上的换页）；
    MusicXML 的 `new-page` 原样档不认（原排版软件按它那张纸断的页），转成 123 写成 `$$` 照留、按它分页（用户定 2026-10-14）；
    其间按自然宽**逐行装满**（`fillLines`：占位与歌词字取并集，放不下退回本行末条小节线后断，`‖:` 断在它前面，只剩小节线的行并回上一行）；一遍一页起头；
    源里的换行会留下不到三分之一宽的短行（跳进源行中间、接着就碰上源换行：094《哈利路亚，祂已复活》回 segno 那一小节）就不照断；
    副歌起头（标了「副歌」，或从这一小节起只剩一行词、前面不止一行）也换行；
    没有 `.Layout` 的**一页最多 4 行**（`pageByRows`）：要断时优先断在副歌起头那行之前（前后两页都至少两行），否则按行数均分（5 行分 3 + 2，不留一页一行）（用户定 2026-10-14）；
  - `.jpwabc` 的 `.Layout`（`BreakPoints` / `LinesPerPage`）：源里换行与遍末换页都不认，按时值插换行 / 换页、`{}` 段不排；
    时值断点之后一拍内就是源里的换行（`$`）的断在源换行上（JP-Word 记的常早半拍到一拍：048《创造奇功》31 对 32，照记的断把行末那个音挤到下一行）；
    各遍接成一长串，同一个符号对象出现几次就另给几个对象（`rowOf`），弧等记号每次出现都画；
  - 纵向：谱行占位盒（数字、歌词按字体盒），块间 `staffDist`、放不满的页把行距摊到 `systemSpread`、剩余空白留在页底（谱从页顶排下来、不竖向居中，成书同；issue 22：会众站着看投影，屏幕下半常被挡）；数字共基线、增时线画成数字字体的「-」字（PPTX 对位）；
  - 每首前一页标题页（首行基线 0.3 页高，逐行下移本行字号），谱页页脚本首曲名 + 「i/n」（各首各自计页）；
  - 展开档笔画见 `style/jianpu.ts` 的 `pptx` 预设（字号 28，16:9 = 960×540、4:3 = 720×540）。
- **成书**（`JianpuLayoutConfig.book`，见 [排版-成书](排版-成书.md)）：原样档的内容 + 展开档的纵向与共基线数字、「-」字；
  不展开反复、不放页眉页脚标题页；断行照文档里的断点（断句写进去的），**单行放不下才折**（`place/reflow.ts::foldLineStarts`）。
- 「这首歌唱成什么样」**一律由 `score/playorder.ts` 从 `ScoreDoc` 推**：简谱形状（文本谱/123/ABC/`.jpwabc`）经 `jianpu/playsong.ts::playDataOfSong`
  （`.jpwabc` 照 `.Repeat`；没有 `.Repeat` 时有 `|: :|` 的照反复记号推、没有的按段逐遍），MusicXML 形状经 `model/playdoc.ts::playDataOfDoc`。
  MusicXML 小节里 `<direction>` 的 D.C. / D.S. / Fine / segno 两条路都认（简谱形状经 `docView` 投到符号上，转出的 123/ABC 写成 `!D.S.!`，`model/directionmarks.ts::directionsAsMarks`）。
  挂哪个符号按拍位找（`directionMarks`）：各元素起点认 `onset`（多声部一小节里各声部从头排），只挑旋律那一路（`melodyLane`）——
  以前把各声部当一条时间线，小钗曲首「欢快 热烈地」、mf、排练号 A 挂到第二声部上、随第二声部一起丢了。
  同一拍上两段文字（「欢快 热烈地」与「pizz」）分行挂在同一个音上：`Chord.sectionWord` 里换行隔开、先出现的在上
  （同 123/ABC 连写的 `"^…""^…"`，ABC §4.19）；简谱 `band.ts` 最后一行落在和弦那一行、前面的往上摞，
  五线谱 `staffpages.ts` 同一拍的几条 `<words>` 也照先写的在上摞。文本谱只能挂一条，用空格连成一行。
- **D.C. / D.S. al Fine 碰上多段词**（`score/playorder.ts::jumpByVerse`，用户定 2026-10-14）：每段一遍、各自回到 Fine——
  A（到 Fine）B₁ → 回 A 到 Fine → B₂ → … → B_V → 回 A 到 Fine 收（096《哈利路亚！感谢主》：副歌在前一行、主歌四段，8 页）。
  A 那几遍取 A 自己的词（A 只一行就都用第 1 段）；每段唱完 Fine 换页。只管一处 D.C./D.S.、一处 Fine、没有 `:|` 与房号的形态，其余照 `RepeatProcessor`。
- **同一房里同时写 D.S. 和 D.C.**（064《啊！圣善夜》一二房 `:|` 上两个都有，三房收尾）：各管一遍，按下一遍的词定——
  下一段词在 segno 之前就有的回曲首（D.C.），只从 segno 起才有的回 segno（D.S.）。收房之后的小节只写了当前这一遍的词、
  没有第 1 段的，遍号不归 1（064 三房之后两小节只写第 3 段，原先归成第 1 遍、靠借词才有字）。
- **没画房号、按词看出来的一房二房**（testdata《爱是不保留》，`playorder.ts::implicitVoltas`）：`:|` 前末 k 小节只写第 1 段、
  `:|` 后紧接的 k 小节只写第 p 段——第 p 遍跳过前者唱后者，之后才回到第 1 遍；曲尾 `:|` 后只写末段的结尾同理。只管没写房号、没有跳转的谱。
- **曲尾只在最后一遍唱的结尾**（文本谱《圣哉三一歌》末段后的「(阿们)」，`playorder.ts::lastVerseTail`）：终止线之后、只有末段写了词的那几小节，
  前几遍唱到终止线为止，只有最后一遍接着唱。两条都要：只看词的话，末段多写一句的普通结尾也会被截。
  最后一遍里它**接在末行末尾、不单独成行**（用户定 2026-10-14；`PlayItem.glueFrom` → `MeasureCut.glue` → `fillLines` 不在这几小节前后断行）。
  演唱顺序里本来就单独成段、只唱一次的结尾（148《求圣灵教导》、255、494：`:|` 唱完四段再接终止线后的「阿们」）同样接在末行（`glueCoda`）；
  都要求**紧接前一项唱下来**——跳过一房接上的二房（爱是不保留）不算。
- **跳转处的双线**（250《主，差遣我》D.S. 前的 `||`）：唱完就跳走的（往回跳的同一遍、一遍的末尾）展开后接的是别处，画成细线。
- **换页口径只在 `walkPlay` 里判**：`endOfPass`（`.Repeat` 的 `P`、按段数逐遍）与**往回跳、换了一段词**（反复、D.C./D.S.）处换页；
  往回跳但还唱同一段词的（D.S. 回去唱到 Fine、只有一段词的反复）**只另起一行**（`jumpBack`，250《主，差遣我》原先一页一行）；
  遍号变了但往前接着唱的（二房后的尾段）**不换**。源里的强制分页另算。
- **歌词行首印着几个段号**（018《伟大的主》副歌第 1 行「1.2.」）：这一行唱那几遍，后面的行依次往后挪（`playorder.ts::labelPasses`，
  第 2 行唱 D.S. 回来那一遍）；D.S. 跳回 segno 与 D.C. 一样算新的一遍。
- **房号（一房、二房的括线）只在原样档画**：展开档已逐遍展开，房号没有意义。画法与五线谱共用 `engrave/ending.ts::addEndingBracket`
  （横线 + 可选两脚 + 房号），**房号纵向从横线往下算**（`labelBaseline`），文字永远不与横线相压；车道定位在 `place/band.ts::placeEndings`：
  - 竖脚对齐小节线的线位，横线让开区间内的墨迹（音符、和弦）与小节线顶；
  - 封口照模型里的 `stop` / `discontinue` 画（各格式的约定在读入时定：123/ABC 最后一房不封口、跟在 `:|` 后碰不到结束线的只罩一小节，见
    [../格式/123格式.md](../格式/123格式.md) §6.1；`.jpwabc` 没有房号写法，读入时推（[源格式-jpwabc](源格式-jpwabc.md)）；MusicXML、文本谱照原文）；
  - 房跨行时把行末仍开着的房号交给下一行，续段不画左脚、不重印房号；原样档房号照原文印（`1,2` 不规整成 `1.2`，用户定）。
- 四档视图 `ViewMode` 是**两组正交状态的组合**，不是四个视图：展开/原样走简谱引擎，五线谱/混排也走 `ScorePainter`（差别只在 `mixedShowJianpuLayer`）。默认**展开**。
- **纸张宽度全仓一份**：`styles.css` 的 `--score-page-max`（960px），四档连同识别叠加视图共用。
  变量里**只放上限、别把整条 calc 放进去**——自定义属性里的 `var()` 在声明它的那个元素上就替换掉了。
- 纸与字号两档各记各的：展开档取 `PAGE_RATIOS`（16:9/4:3，1 单位 = 1pt，**恒分页**）；
  原样档取 `PAPER_SIZES` 实际尺寸 + 一档**长图**（出厂默认，宽同 500 首那张纸 `150×216mm`，425pt；出厂音符字号 12）。
  **「换纸」与「要不要分页」本来就是同一个决定**，所以长图是纸张列表里的一档而非勾选框。
- 导出 PPTX 取的是**展开档**那一套，哪怕屏幕正停在原样档。
- 「每页行数」（写进 `.Layout`）**只归展开档**——原样档照源里的 `$` 换行，行数由内容与纸说了算（用户定：`.Layout` 是投影片的分页，不照搬到纸上）。
- **原样档的尺寸照 500 首，不照投影片**（用户定：28 是展开档的大字号）：笔画按音符字号的比例给（`style/themes.ts` 的 print 主题，em = 音符字号：
  小节线 1/14、终止线粗线 1/8、减时线 0.05、弧厚 0.2、弧顶上下限 0.45 / 0.28、拍号分数线 1/14、多段歌词行距 1.25；角色字号歌词 1、和弦 0.85、
  标题 1.8、署名 0.9、房号与三连音 0.6；和弦排成纯文本），适配器 `style/jianpu.ts` 里不留数。
- **每行 N 小节**（工具栏「分行」第三档，`jianpu/phrase.ts::barLines`，用户定 2026-10-27，issue 25）：与按乐句重排一样**重写原文**、同一套还原；
  只按主旋律的小节线数，原有换行（连同小节中间的）作废；不满的第一小节（弱起）不计、并进首行；源里原有的换页照留、每页从头数，
  不另造换页；末行不足 N 照留。原样档有一行放不下时下面那条整首重断会把 N 冲掉，所以重排时按乐句重排同一把尺子量一遍、
  放不下就在状态栏提示（`barLinesOverflow`）。小节等宽（同一行各小节一样宽）不做：那是和弦谱的排法，常规简谱按内容定宽。
- **原样档整首重新断行**（`place/reflow.ts::reflowLineStarts`，用户定）：源里每一行都放得下就照原文的行；有一行放不下（窄纸），
  就不认源里的换行，只在小节线处断、求各行余白平方和最小——行长均匀、中间没有短行。源里的换页仍是硬断点。长图与分页纸同宽，一样做。
- **原样档的版心与页眉**：连谱号、段号也收在版心里（用户定）——先排一遍量出它们伸出音符起点多少（段号按首字**实际**位置算，
  `compose/page.ts::systemMetrics`），版心左缘让出这一截整份重排（`compose/index.ts` 的 `leftIndent`）。
  页眉（`place/header.ts::placeHeader`，照 500 首的成书页眉）：标题居中、**调号拍号在左**、**词曲署名右对齐逐行**，调号拍号与最后一行署名同基线；
  一条署名里换了行（MusicXML `<creator>`、`.jpwabc` 的「作词：…\n作曲：…」）照原样分行；署名照原文印、不补「作曲：」（用户定）。
  长图把多首接成一张时每首的页眉、页脚都在（`PlacedPage.headers`）；接页时下一页首组的头顶（房号、和弦、弧）至少让开上一页末行一道组间空。
- **自动段号**（`place/song.ts::autoVerseNumbers`，样式键 `verse-numbers`）：只给源里没写说明的行补；源里有 `<1.>` 或首字自带「1.」（MusicXML「1.圣」）的行照源印。
- **原样档的上方带**按墨迹堆叠（`place/band.ts`）：转调标签在和弦之上；同一行的和弦同基线；段落词与和弦同大、避开转调排在它右边；
  房里的 `Fine` / `D.S.` 排在房号线之上；松叶在和弦之上；延长记号、力度让弧。
- **`.jpwabc` 原样档**照画 `|: :|` 与推出来的房号（用户定 2026-10-14：反复记号既然参与演唱顺序，谱面也要看得出）。

## 已知限制

- 展开档只排一条旋律；和弦与首调号拍号不出现
- `.jpwabc` 某些曲目的歌词归属语义未定（同一小节被两条 W 行认领时谁优先）

具体曲目的未修版面问题记在本地私有仓库的待办（不入库）。
