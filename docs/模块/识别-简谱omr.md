# 识别：简谱 OMR（图片 / PDF）

**判据全录** → [../实现/OMR-简谱识别.md](../实现/OMR-简谱识别.md)、[../实现/矢量PDF识别.md](../实现/矢量PDF识别.md)

## 职责

简谱图片/PDF → 123（经 `ScoreDoc`）/ 文本谱原文。**不产出 MusicXML**（要的话就是 123 文档的导出；只有五线谱识别出 MusicXML）。**全本地、可离线**（连通域几何启发 + PaddleOCR）。
另含矢量（文字转曲）PDF 的对象层抽取。

## 吃什么吐什么

```
图片/PDF → 预处理/二值化 → 连通域 → 归类 → OCR（数字/歌词）→ RecognizedScore
        → ScoreDoc → 123 / 文本谱原文（换格式只重走 emitter，绝不重跑识别）
```

## 关键判据
- **核对视图可编辑**（`reproject.ts`）：框 ↔ 当前模型元素靠随编辑迁移的 `meta` 原文区间（`OmrController.idMapOf`），**框序不变**——命中层 `data-i`、
  试听高亮照旧；只换框里显示的值（唱名、八度、升降号、减时线、附点、增时线、延长号），与原识别不同的标 `edited`；对不上元素的框标 `deleted`；
  模型里有、框里没有的（新插的音）按同一声部前后两个有框的音插值定位，命中层另带 `data-id`。改过的歌词在原位盖白底新字。
  核对模式下 `App.reload` 不排版、只重建索引并重画叠加层（底图 PNG data URL 按二值图缓存，免得每按一键重编码；保住滚动位置）。
  拍数红框在可编辑时由可视化编辑按当前模型画，识别完那一份只在不能编辑（JPWABC / ABC 产物，没有 `meta`）时画；两种红框右上角都标差额（`beatcheck.ts::beatTag`，`−♩`）。
  `F8` / `Shift+F8` 把可疑项（`OmrController.doubtStops`，按 `meta` 区间给原文位置）与拍数不对的小节并成一张按原文位置排的表，从当前选区往后 / 往前找。
  Alt+点原图空白处补漏识的音：照抄选中那个音的原文，插在点的位置左边那个识别框的音后面（`sourcePoint`，同五线谱对照）。
- **原图片段跟随**：排版稿里选中音符，按同一份映射找到框、取原图那一行（`renderRowSource`，只画原图不叠识别结果），以这个音为中心裁约 8 个行高宽放进右下角小窗。

- **`src/omrkit/vector.ts` 及其 import 链不得触碰 canvas / OffscreenCanvas / document**——Node CLI 要 import 它。
- PDF 栅格化**必须**用 `getDocument({wasmUrl})`。
- **归类判据一改就要重跑 `../dev/scripts/gen-glyphdict.mjs`**。
- 矢量路的硬指标是**未归类对象数**。
- OCR 兜底后仍读不出的字形**宁可留空也不编造**（`■` 一项曾多出 337 处）。
- 干净谱面上减时线粘着点/数字：**按本页统计线粗剥掉线带、剩下的每块都得认得出**，认不出就整块不动（`stripUnderline`）。
- 谱后诗行只有**每段音节数等于第 1 段起字音位数（±2）**才算附段歌词，否则整块当正文丢掉。
- 弧按质心罩音与按两端配音不一致时**由歌词裁决**：后者是一字多音的形（起音有词、其后各音各段都没词）而前者不是才改（`resolveSlurRefits`）。
- 附点与短增时线尺寸重叠时按**扁度**分：宽 ≥1.8 倍平均墨厚的是 `-`（1863 小节末 8×4 的短横，同页附点 5×4）。
- 外弧底下两条内弧首尾相接（M 形）时按尖谷切开各认一条；中间那个音既收又起，123 写 `((5 (3) 3))`。
- 高八度点溶在弧块中间（交脚/弧脚压着点）：按每列最低那段墨的厚度切出点，弧块须拱起；拆内弧时遮掉弧框里的小点（`splitArcInnerDots`）。
- 顿音 ▼ 与重音 > 都靠**形状**跟八度点分（倒三角逐行收尖；> 右缘中间最右、中间行左缘离开左边即中空），认出来就从 `dots` 摘掉。
- 倚音底下的减时线条数（`graceDivLines`）写进倚音的符号时值（一条 = 八分 `{2}`，两条 = 十六分 `{2_}`）。
- 数字格整格读成 `8`/`B`（粗体小图把 3/5/6 的开口糊成闭环）时改取 0–7 的打分首位；中带左右墨迹间夹着空白的 0 是真空心环，不按「糊死的 3」复原（`midbandHole`）。
- 「读成 1 的宽块改判 7」比的真 1 宽只取不高过数字中位高 1.2 倍的（和弦行里的竖线也读成 1、更窄）。
- 和弦左缘落在两音之间（0.35–0.65）、两音间隔着小节线、左缘已到线前 0.3 字号以内的，归下一小节首音——下一小节首音另有和弦时不挪。
- 上一行末开口、本行首是 `‖:`：不并成跨行小节，反复线是本行首小节的左线；某段词从 `‖:` 之后才印时，`‖:` 之前的行不照抄第 1 段词。
- 弧顶粘着上方的和弦字（括号、`Am` 的 m 脚）：块的下包络按相邻列落差切成平滑段，最长一段 ≥1.2 字号宽、薄、两端低于最高处 0.15 字号以上就是弧，
  剩下的墨须整个在弧顶以上 0.3 字号起笔，拆成弧与字（`splitArcUnderGlyph`）。入口只要块高 > 0.8 字号（八分音符上的短弧粘 m 只有 1.02 字号，青年诗歌 48）；
  弧两端陡、竖着量比中位厚得多，每列底段墨厚不过 0.2 字号的整段归弧，再厚的（字脚连着弧）只取一个中位厚。
- 谱行行首连着两个以上近方、不比本行数字矮的核，其后至少三个核且七成不是近方的：是行首标签（「前奏：」），摘掉后认字挂段落词。
- 判和弦行时，单独一块只读出「一 / - / 1」的段不计入（和弦行里夹着的弧）。
- 一行歌词里字落在音符正下方（0.4 字号内）的不到六成，而同谱行至少两行别的歌词都在八成以上、它低于它们中位 0.35 以上：是夹在谱行间的普通文字，不当歌词。
  只比同一谱行——四声部谱的词对的是另一声部的音，整行几段一起低。
- 行首括起来的「(副一)」「(副)」落在首音左侧：剔出正文、照原样记成行首标签，不参与段号映射。
- 长音上方挤着几个和弦、都没越过下一个音：依次挂到本音的增时线上；隔开一个字号以上的同名和弦是两个记号。
- 歌词/和弦行的 OCR 原文先把全角拉丁字母、数字、＃折成半角（中文标点不动）。
- 送歌词/和弦 rec 的图上抹掉已归了别处的墨：延长记号、最终谱行里带临时号的音左边那个 ♯/♭、segno、端头立着和弦字母的独立细弧（按连通整条抹）。
  别处的弧不抹（两声部间、英文歌词下的弧抹了 rec 反倒不稳）。
- 和弦级数不收单独的「1」：小节线顶、弧头常被读成 1（`Bb1`）。
- 单声部行中间的细粗并排两根，线前两小节内挂着 Fine 才认作终止线；行首带 segno 的不并跨行小节，上一行末记不可见线。
- 歌词行里单独一个「一」不在任何音下（离最近的音中心超过 0.6 字号）：是字间破折号，并到前一个字上、不占音位。
- 单声部行上点顶比歌词字顶线高出 0.15 字号以上、紧贴数字（0.45 字号内）的低音点照收，不看它下方有没有墨：字顶笔画的顶与字顶线平齐。
- 多道减时线逐层验距之外还要**对齐**：下一道落在上一道两端以内（冒出不过 max(2px, 0.06 字号)）；两头都比上一道宽出去的是歌词字的顶横。
- 比数字还高（1.25–1.45 倍字高）、整个悬在右邻数字左上方（顶高出 0.5、底高出 0.3 字高）、离数字一个字号内的块，单声部行上按形状再认 ♯。
- 一块墨只归一样东西：顿音三角落在和弦框里的（和弦下标的小「7」）让给和弦；块首括号里的和弦紧挨在左边已有和弦（缝不到 1.2 字高）时是被拆开的备选，让给主和弦。
- 谱后以「注：」起头的行收作页脚注（接续行并进同一条），记 `pageText.bottomLeft`（文本谱 `BL:`、123 `I:bottomleft`）。
- 临时 ♯ 的宽度门（< 0.85 倍数字宽）在单声部行上也放给**顶底都悬高**（顶高出 0.25、底高出 0.3 字高）、形状判得出 ♯、脚下没压线的块。
- 下滑音 ↘（数字右上方一笔向右下弯、带箭头的细线）与数字差不多高、会进数字核读成音：紧贴左邻数字（缝 ≤0.3 字号）、顶不低于它、
  箭尖收在它底线以上 0.1 字高，**横向墨段中位长不到左邻数字的六成**，且下部四成里最宽一行 ≥ 上部箭杆中位墨宽 1.8 倍（箭头）的，
  摘出数字核、记在左邻音上（123 `!xhy!`）。
- 弧脚收在行末小节线顶上的矮块（1.6–1.8 字号）只在**只有一根竖线且贴着块边缘**时按小节线拆（`untangleBridged`），两侧各一根的框不拆。
  跨两声部的长线（≥3.5 字号）整根抹掉、只擦线宽，再把被线隔开的两截弧接回。
- 参照歌词互证：先按**演唱顺序**展开识别歌词再与参照整篇对齐（参照是反复写全的），展开后 F1 反而低 0.1 以上就退回谱面顺序并报疑反复；
  只有**两头都贴着同字**的一两处不一致才逐字处理，改字要参照字在 OCR 候选里且得分 ≥ 首选的 0.05（按歌词库 336 处裁图定）；
  己/已/巳、人/入、儆/做、瞎/唐、徬/傍 按词组定字（歌词文件在这几处常写错），他/祂、你/祢 按谱面取字形，其余版本用字只报不改；
  改动所在处还有别的字对不上就标「待复查」。
- 歌词识别的缓存按**条的内容指纹**寻址——判据一动缓存就落空，**掉一点先别当退化**。
- 多声部靠左侧连谱号分组（`StaffRow.system/voice`），**全曲齐整才启用**；两声部挨近带出来的几条判据（点归更近的数字、
  弯的横线不算减时线、别的谱行带里的弧候选不算……）**只在连谱号括着的声部行上开**——单声部谱数字下面紧跟歌词，
  放开就误伤。

## 可疑项（复核标黄）

识别主干不改判定，只在「差一点」的地方记一笔（`JpNum.doubt` / `lyricDoubt`），核对视图画黄框（`overlay.ts::doubtItems`）、工具栏「N 处可疑」逐个跳：

| 理由 | 判据（`jianpu.ts`） |
|---|---|
| `note.offRow` | 音框纵向离本行中位数超过 0.45 字号（印在音上方的小字替换音、附注里的数字） |
| `oct.inkAbove` | 没认出高音点，但数字正上方中间几列的墨像点：粘在弧上的局部鼓起（高 ≥ 弧身 1.8 倍、≥0.2 字号，最下三成横宽 0.18~0.5 字号），或孤立的实心小块（`dotInkAbove`）。剥弧时点被一起带走、没进点候选 |
| `oct.oddShape` | 收下的八度点不实（墨 < 55%）或一边长出一截（长短边比 > 1.7）：小尖角、重音记号 |
| `oct.offCenter` | 紧贴数字上下的点只因水平偏了一点（不到居中门限 1.3 倍）被剔 |
| 歌词字 | 每个汉字取逐字候选（`LyricHooks.rankAlts`），第一名不是识别结果、或第一名比第二名高不了 0.7（`LYRIC_DOUBT_MARGIN`）。识别时 `review: false` 不跑这一遍（每首多 1.5~2 秒） |

量法：`../dev/scripts/doubt-eval.mjs`（testdata 单声部 GT，与 GT 逐音对齐）。2026-10-01：6575 个音真错 7 个，标 63 个、7 个全中（查准 11%、查全 100%）；
歌词字（两边都有字、字不同的算错）6942 个错 18 个，标 66 个、中 12 个（查准 18%、查全 67%）。**真错样本少，门限是照这几处调的，换一批谱效果可能打折。**
试过、不用的：数字格 OCR 第一名与第二名的分差（0.4 标 34 个、真错 0 个——真错多是八度点与多认的音，与数字认得清不清无关）；
收下的点各道门余量小、被上下文规则否掉的点（标 45 个、真错 0 个）。位图五线谱没有可疑项（F8 那张表在五线谱对照里只有拍数一种）。

## 歌本切分（`omr-cli.mjs split`）

分页的简谱诗歌集（扫描 PDF 或页图文件夹）→ 输出目录里一首一张 `曲号 曲名.jpg`，只在命令行。一页多首按标题切开，
一首跨页按序竖着拼，去掉页脚页码，拼缝处用本首的系统间距，边距取全书版心距纸边的分位数、切口处补纸色；
裁拼一律在源图原分辨率上做（PDF 取每页内嵌的源图，不渲染不缩放）。书内首句 / 经文目录自动整页 OCR，
投票得「曲号 → 页码」，用来给标题配号并报缺号、重号、起始页不符，写到 `切分报告.txt`。

| 文件 | 作用 |
|---|---|
| `booksplit/layout.ts` | 单页几何：连通块 → 横向带（谱行连同弧线、八度点）；标题大字、小节线、页脚候选；标题行粘上谱行时在首排大字底边切开 |

## 已知限制
- 歌本切分只认「标题行有 `1=` 调号，或标题字比本页歌词大且读得到曲号」的版式；矢量 PDF（没有内嵌位图）不收，要先导出成图片；
  拼缝按系统间距排、页内间距照原样，不重排页内各行

- 矢量 PDF 路编辑器未接，见 待办（本地私有仓库 `dev/docs/待办/重构与编辑器.md`） R3
- 版权说明/注记行：与谱行同高时会被 `groupRows` 并进谱行，现按「连续 ≥5 个读作 0 的核」截掉（只对第一谱行以下开）；作为歌词行时按与音符横跨的**重叠**算 cov，印在音符旁边的注记落榜。整段压在音符正下方的注记仍可能被当成歌词行
- 脏页上粘连成一块的双层减时线只数得出一层（92/95 共六处十六分音符，按列高剖层试过，误伤三首老语料，未上）；整个溶进弧脚的高八度点仍有切不出来的（1801 一处）。都已按图写进 GT
- 跨行圆滑线的续弧若与同罩这几个音的行内弧粘成一块，行内那条会跟着丢（1806）
- 整体右偏的弧只在谱下配了词时才改配（按一字多音的形裁决）；没配词的谱仍按质心罩音，起音会漏
- 小图（1940 宽 620px、字高 14px）上的波音、重音认不出，第 7 行的波音还被当成高八度点；弧脚压着的高八度点、行末那组首尾相接又跨行的弧也没认全（均已按图写进 GT）
- 速度记号只认四分与附点四分（`♩=`、`♩.=`）；八分、二分音符的速度记号字形路不认，只有 det 文本行那路（且按四分记）。附点只在合成图上验过，testdata 没有真样张
- 小节线从数字正中穿过（排版挤压）时，两者粘成一块被读成别的数字、小节线也跟着丢；节中双细线 `||` 读成单线（均见 2152）
- 78《马槽歌》音符、slur 均 100，剩歌词两个形近字；1《圣哉三一歌》音符 100，只漏 `3⌒♯4` 那条弧。均已按图写进 GT
- 局部多声部（前几行单声部、后面几个系统带连谱号分声部）只认两声部系统（946《大地音韵飘》）；三、四声部的系统缺连谱号时
  按众数把孤行补成系统那条与「前几行单声部」分不开，整页仍退回单声部
- 矢量路：和弦剩 4.5% 差异、调号 17 首（原书转过调）、反复与房号只记录不计入差异、
  OCR 形近字误判、标点互换约 100 处、升号/上标 7 混进歌词约 400 处
