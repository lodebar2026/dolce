# 排版：简谱引擎

**判据全录** → [../实现/简谱纵向栅格.md](../实现/简谱纵向栅格.md)、[../实现/文本谱.md](../实现/文本谱.md)、[../实现/乐句排版.md](../实现/乐句排版.md)、[../实现/歌词标点挤压.md](../实现/歌词标点挤压.md)

## 职责

简谱只有**一个引擎、一把尺子**（2026-10 合并：原先的简谱引擎 `Layout`/`Line`/`LayoutOptions` 与原样文档布局两套并存，同一份谱换个格式观感就变；
旧引擎已删，判据搬进来了）。各格式（`.jpwabc`、123、ABC、jcx、jianpu-ly、文本谱、MusicXML）的原样档、展开档、PPTX、帮助谱例与成书都走它。

整份 `ScoreDoc` → 排版行视图（`pu/slots.ts::docView`：歌曲 → 页 → 谱行组 → 声部行，元素带 id）→ **定位**（`place/`）→ **绘制**（`compose/`）→ 页面树。
多声部与单声部同一条路：同一拍位的符号归一列（`place/spacing.ts::placeColumns`）。

## 吃什么吐什么

```
ScoreDoc → docView（排版行视图）→ place/（定位，只碰注入的量具 InkMeasurer）→ PlacedPage[] → compose/（绘制、打身份标签）→ PageItem 树
                                                                                                        ├→ renderPageSvg → SVG
                                                                                                        └→ walkPageItem → DrawList（成书）/ PPTX 形状
```

## 各档的开关组合

| 档 | 开关 | 成行 | 纵向 |
|---|---|---|---|
| 原样（分页 / 长图） | — | 照源换行，放不下整首在小节线处重断（`reflowLineStarts`） | 组间按头顶实高让位，长图各页接成一张 |
| 展开 / PPTX | `expanded` | 逐遍展开、一遍之内逐行装满（`fillLines`）；`.jpwabc` 有 `.Layout` 按时值断 | 谱行占位盒紧挨、放不满摊开（`slideBlock`），数字共基线、增时线「-」字 |
| 成书 | `book` | 照写进文档的断点，单行放不下才折（`foldLineStarts`） | 同展开档；不放页眉页脚标题页 |
| 帮助谱例 | `snippet` | 同原样 | 不放页眉页脚，首组贴上边距 |

细节见 [排版-展开与原样两档](排版-展开与原样两档.md)、[排版-成书](排版-成书.md)。

## 关键判据

- **两段式**：`place/` 只定位、所有 y 在这一段定死；`compose/` 只绘制。量宽、断行、分页都在 `place/`，绘制端不回头改坐标。
- **一把尺子**：样式值只从 `JianpuStyle` 取（`style/jianpu.ts::jianpuStyleOf`；成书 `style/book.ts::bookJianpuStyle`），
  同一档里各格式生效值全等（`dev/scripts/ruler-compare.mjs` 41 项）。栅格只带随音符字号缩放的步进。
- 数字上下那一摞（高音点 / 减时线 / 低音点）走 `engrave/stack.ts` 的等距叠层（墨迹到墨迹 `stack-gap × 数字墨迹高`）；弧、连音、记号再让 `slur-gap`。
- 三连音两种画法（`tuplet-style`）：`bracket` 括线、`arc` 两段弧（同页 slur 那条月牙挖掉数字那一截）；连音括线与房号同一个线宽。
- 八度点、附点、反复点一律矢量圆；附点圆心与数字墨迹中心等高。拍号竖向只认拍值字号，分数线与小节线同粗（原样主题 `time-sig-rule`）。
- 小节线纵向按 `barline-height`（基线上 3/4、下 1/4）；弧、延音线罩住小节线也不截线（用户定）。
- **不能用 `<text>.getBBox()` 核对数值**：SVG 对 `<text>` 返回的是行框不是墨迹；SMuFL 字形的字体盒约 4 em，量墨迹走 `engrave` 的紧包围盒。
- **跨行的弧两截都画**：起头那行画到行末那个音右侧半格，收尾那行从行首起弧；敞口那截的高度只认真有的那一端。
- **小节左线上的反复起点**：排版行视图不出左线，挂在前一小节右线上（`repeatForwardAfter`，`pu/slots.ts::carryToPrevBarline`）；
  画线（`barspec.ts`）与推演唱顺序（`pu/phrasesong.ts::buildMeasures`）都认它——漏认的话 `|] |:` 之后那个 `:|` 跳回曲首（116《献上感恩》）。
- **器乐分谱的几样**（123 / MusicXML 来源，文本谱不产生）：弓法、单音震音走 `pu/glyph.ts::ORNAMENTS`（`sg`/`xg`/`trem1–4`，进上方那一摞）；
  排练号（`rehearsal=A`）不进力度那一组横排，等别的都落定再单独摆（`band.ts::placeRehearsal`）：左缘对齐那个音、抬过这一段一切墨迹，`ink` 就是方框；
  多小节休止在视图里并成一个元素（`model/multirest.ts`，`NoteElement.multiRest`），画一道粗横杠加小节数（`compose/note.ts::paintMultiRest`）；
  速度数字（`Metadata.tempoMark`，`♩=144`）印在调号拍号下一行——只给非文本谱来源，文本谱的 `J:` 数字只管播放、谱本上不印。
  终止线、双线后接起反复（`|] |:`）画成 `|:`（`barspec.ts`）。
  和音（123 `[13]`、MusicXML 同一 voice 的和弦）：视图里最低的音当本音、其余进 `NoteElement.stack`（`pu/slots.ts::noteOf`），
  全尺寸数字往上叠（`place/vertical.ts::stackedDigits`：上面那个的墨迹底连同低音点，离下面那摞的顶连同高音点两道叠层空），
  减时线只在本音下，每个数字各带变音、八度点与附点；`stackTop` 算到最上面那个，弧、记号、上方带自然让开；临时记号让位取几个里最宽的。
  琶音（`arp`）画在和音左边，画法与五线谱同一份（`engrave/arpeggio.ts`，SMuFL 波浪转 90°，旋转放在字形叶子上——套 Group 会被 update() 冲掉）；
  左边让位并进 `accidentalLeadOf`。叉形、圈叉符头（`!head-x!`、`<notehead>circle-x`）印成节奏音符 `X`（`slots.ts::noteOf`）。
  同时敲的几个节奏音符（`[X@E5X@F5]`、打击乐谱的 `<unpitched>` 和弦）照和音把 `X` 往上叠（`StackedNote.pitch` 9）。
- **同一谱表的第二声部**（123/ABC 的 `&`、MusicXML 同一 `<staff>` 的第二个 `<voice>`）：分路判据只一份（`model/innervoice.ts::lanesOf`：
  主行是 `melodyLane`，同谱表编号次小的 voice 是第二声部，第三路起与别的谱表排不下）。行视图（`slots.ts::buildRow`）把一行里连续几个带第二声部的小节
  并成一个并排块（`InlineLayerElement`，`below: true`），挂在段首；不满小节的补不可见休止（不画减时线），块里小节之间补普通线。
  排法同文本谱 `{dsb…}`，只是上下对调——主行在上、第二声部在下（`layers.ts`，`splitRise` 取负）。
  **下行先按自己的节奏排、与主行一起归列**（`layers.ts::belowLayerLines` → `placeColumns`，`SpacedLine.barBase` = 从主行第几小节起）：
  第二声部的拍位常比主行细（主行八分、下行十六分），只按比例往主行的列里塞会挤成一团（八段锦小钗）。文本谱的 `{dsb}` 两行写法一致，仍按主行的列落。
  MusicXML 的 `<forward>` 空拍在投影时补成不可见休止（`jianpuproject.ts::fillVoiceGaps`），以前投影直接删 voice > 1。
- **曲首文字与力度互让**（`band.ts::liftTextsOver`）：力度、术语贴音落定后，压着的段落词、转调标签整条上提到它之上（全局信息在外、局部信息在内），
  连带被顶到的别的段落词/标签一起推；先落定的记号压上后一组时后一组抬到它之上。
- 乐句排版：行长以小节数计，「放不放得下」由 `painter.ts::measureDocument` 按当前档的纸与样式量出的真实坐标判（按元素 id，只量带歌词的旋律声部；
  文本谱不清换行、`naturalSpans` 逐行接着量）。文本谱与多声部的原样档不给尺子（一句一行）。
