# 排版：简谱引擎

**判据全录** → [../实现/简谱纵向栅格.md](../实现/简谱纵向栅格.md)、[../实现/文本谱.md](../实现/文本谱.md)、[../实现/乐句排版.md](../实现/乐句排版.md)、[../实现/歌词标点挤压.md](../实现/歌词标点挤压.md)

## 职责

简谱只有**一个引擎、一把尺子**（2026-10 合并：原先的简谱引擎 `Layout`/`Line`/`LayoutOptions` 与原样文档布局两套并存，同一份谱换个格式观感就变；
旧引擎已删，判据搬进来了）。各格式（`.jpwabc`、123、ABC、jcx、jianpu-ly、文本谱、MusicXML）的简谱档、投影档、PPTX、帮助谱例与成书都走它。

整份 `ScoreDoc` → 排版行视图（`crates/model/src/view/slots.rs::doc_view`：歌曲 → 页 → 谱行组 → 声部行，元素带 id）→ **定位**（`place/`）→ **绘制**（`compose/`）→ 场景树。
多声部与单声部同一条路：同一拍位的符号归一列（`place/spacing.rs::place_columns`）。
下表路径未写 crate 的都在 `crates/layout-jianpu/src/`。

## 吃什么吐什么

```
ScoreDoc → doc_view（排版行视图）→ place/（定位，只碰注入的量具 Ink）→ PlacedPage[] → compose/（绘制、打身份标签）→ 场景树（dolce-engrave::scene Node）
                                                                                                        ├→ page_svg → SVG
                                                                                                        ├→ 身份表（index.rs）→ 播放高亮 / 点选
                                                                                                        └→ DrawList（成书，scenedraw.rs）/ PPTX 形状（pptx.rs）
```

## 各档的开关组合

| 档 | 开关 | 成行 | 纵向 |
|---|---|---|---|
| 简谱（分页 / 长图） | — | 照源换行，放不下整首在小节线处重断（`reflow_line_starts`） | 组间按头顶实高让位，长图各页接成一张 |
| 投影 / PPTX | `expanded` | 逐遍展开、一遍之内逐行装满（`fill_lines`）；`.jpwabc` 有 `.Layout` 按时值断 | 谱行占位盒紧挨、放不满摊开（`place/song.rs::slide_block`），数字共基线、增时线「-」字 |
| 成书 | `book` | 照写进文档的断点，单行放不下才折（`fold_line_starts`） | 同投影档；不放页眉页脚标题页 |
| 帮助谱例 | `snippet` | 同简谱档 | 不放页眉页脚，首组贴上边距 |

细节见 [排版-投影与简谱两档](排版-投影与简谱两档.md)、[排版-成书](排版-成书.md)。

## 关键判据

- **两段式**：`place/` 只定位、所有 y 在这一段定死；`compose/` 只绘制。量宽、断行、分页都在 `place/`，绘制端不回头改坐标。
- **结构是迁 Rust 时重新设计的，判据与阈值照旧 TS 引擎搬**（[../架构.md](../架构.md) §8）：
  - **显式驱动**：`layout_jianpu` 是一个循环，每遍产出 `PassOut::{Done, Reflow, Indent}`（重排断行、左缘让段号），遍数与触发判据同旧递归，`page-check` 的遍数断言守住。
  - **对象身份改下标**：行视图带 `ids` / `owners` / `passes`，定位结构里挂在哪一项、两端是谁都存下标或元素 id；上方带的盒钥匙是枚举，`topAt` 闭包改成逐次加偏移（浮点次序同 JS）。
  - **每次排版从干净的行视图起排**：段落词挪行尾、自动段号改的是本次克隆出的那份（`Rc::make_mut`），不改按文档缓存的视图——旧 TS 改缓存，同一文档换样式再排会带上上次的改动。
- **一把尺子**：样式值只从 `JianpuStyle` 取（`crates/engrave/src/style/jianpu.rs::jianpu_style_of`；成书 `dolce-engrave::style/src/book.rs::book_jianpu_style`），
  同一档里各格式生效值全等（`dev/scripts/ruler-compare.mjs` 41 项）。栅格只带随音符字号缩放的步进。
- 数字上下那一摞（高音点 / 减时线 / 低音点）走 `dolce-engrave/src/stack.rs` 的等距叠层（墨迹到墨迹 `stack-gap × 数字墨迹高`）；弧、连音、记号再让 `slur-gap`。
- 三连音两种画法（`tuplet-style`）：`bracket` 括线、`arc` 两段弧（同页 slur 那条月牙挖掉数字那一截）；连音括线与房号同一个线宽。
- 八度点、附点、反复点一律矢量圆；附点圆心与数字墨迹中心等高。拍号竖向只认拍值字号，分数线与小节线同粗（原样主题 `time-sig-rule`）。
- 小节线纵向按 `barline-height`（基线上 3/4、下 1/4）；弧、延音线罩住小节线也不截线（用户定）。
- **不能用 `<text>.getBBox()` 核对数值**：SVG 对 `<text>` 返回的是行框不是墨迹；SMuFL 字形的字体盒约 4 em，量墨迹走 `dolce-engrave` 的紧包围盒。
- **跨行的弧两截都画**：起头那行画到行末那个音右侧半格，收尾那行从行首起弧；敞口那截的高度只认真有的那一端。
- **小节左线上的反复起点**：排版行视图不出左线，挂在前一小节右线上（`repeatForwardAfter`，`dolce-model::view/src/slots.rs::carry_to_prev_barline`）；
  画线（`barspec.rs`）与推演唱顺序（`dolce-model::view/src/phrasesong.rs::build_measures`）都认它——漏认的话 `|] |:` 之后那个 `:|` 跳回曲首（116《献上感恩》）。
- **器乐分谱的几样**（123 / MusicXML 来源，文本谱不产生）：弓法走 `dolce-engrave/src/jpglyph.rs::ornament`（`sg`/`xg`，进上方那一摞）；
  单音震音（`trem1–4`）照 GB/T 46845 7.8.2.1 记在数字**右下角**：左低右高的几道细斜线，排在附点之后，和音每个数字各画一个
  （几何只一份 `dolce-engrave/src/jptremolo.rs`，列宽 `place/spacing.rs::item_box` 按它让出右侧）；
  排练号（`rehearsal=A`）不进力度那一组横排，等别的都落定再单独摆（`place/band.rs::place_rehearsal`）：左缘对齐那个音、抬过这一段一切墨迹（左右各多看半个数字宽），
  `ink` 就是方框；照 GB/T 46845 5.9.4「段落序号应使用大字号」与 5.9.5 谱例取音符字号的 0.9、粗体；
  文字自带方头括号的（`rehearsal=【A】`，八段锦）照原样排字、不套框。
  多小节休止在视图里并成一个元素（`crates/model/src/multirest.rs`，`NoteElement.multiRest`），照 GB/T 46845 6.3.7.3 谱例画 ├─14─┤：横线与两头竖线一样粗、
  上方居中印小节数（`compose/note.rs::paint_multi_rest`）；
  顿音（staccato / staccatissimo）照 7.9.2.2 谱例画宽略大于高的实心倒三角（借 SMuFL noteheadTriangleDownBlack，`dolce-engrave/src/articulation.rs`）；
  **整首没有歌词的按器乐谱排**：力度记号、渐强渐弱照 7.3.8 a）、7.3.6.3 记在谱行**下方**（`place/band.rs::place_below`：整行一条线，落在本行最低墨迹、
  连同并排下行之下，松叶碰上同处的力度字就让开），声乐谱照旧在上方；
  速度数字（`Metadata.tempoMark`，`♩=144`）印在调号拍号下一行——只给非文本谱来源，文本谱的 `J:` 数字只管播放、谱本上不印。
  终止线、双线后接起反复（`|] |:`）画成 `|:`（`barspec.rs`）。
  和音（123 `[13]`、MusicXML 同一 voice 的和弦）：视图里最低的音当本音、其余进 `NoteElement.stack`（`dolce-model::view/src/slots.rs::note_of`），
  全尺寸数字往上叠（`place/vertical.rs::stacked_digits`：上面那个的墨迹底连同低音点，离下面那摞的顶连同高音点两道叠层空），
  减时线只在本音下，每个数字各带变音、八度点与附点；`stack_top` 算到最上面那个，弧、记号、上方带自然让开；临时记号让位取几个里最宽的。
  琶音（`arp`）画在和音左边，画法与五线谱同一份（`dolce-engrave/src/arpeggio.rs`，SMuFL 波浪转 90°，旋转放在字形叶子上——套 Group 会被 update() 冲掉）；
  左边让位并进 `place/vertical.rs::accidental_lead_of`。叉形、圈叉符头（`!head-x!`、`<notehead>circle-x`）印成节奏音符 `X`（`dolce-model::view/src/slots.rs::note_of`）。
  同时敲的几个节奏音符（`[X@E5X@F5]`、打击乐谱的 `<unpitched>` 和弦）照和音把 `X` 往上叠（`StackedNote.pitch` 9）。
  和音的延音线：同一对和音之间的几条 `tied`（MusicXML 一音一条、123 `[1~5]`）在 `dolce-model::view/src/slots.rs::chord_tie_digits` 归组，连上每个数字的是整和音的弧，
  只画一条、在叠印顶上；只连其中几个的记 `FanqieMark.digits`（两端各是第几层）。连最下面那个的画在叠印**下方**、开口朝上
  （`place/marks.rs::tie_below`，端点线在两端数字、减时线、低音点之下一道叠层空；扁平式只会朝上画，这条关掉），
  歌词与器乐谱下方那条带照 `below_arcs_bottom` 让开；连最上面那个的照常在上方；连中间那层的（三个以上的和音）也画在上方——数字之间只隔两道叠层空，放不下弧。
- **上 / 下滑音**（`shy` / `xhy`）照 GB/T 46845 7.6.4.3 是**直线短箭头** ↗ / ↘，记在数字（连同附点）右侧偏上，不进上方那一摞；
  尺寸照规范谱例量（横 0.5 H、竖 0.85 H），离数字只空 0.1 H（谱例 0.38 H，用户定尽量少占横向），列宽只补伸出字面宽的那截
  （几何一份 `dolce-engrave/src/jpslide.rs`）。弯箭头 ↷ 在规范里是回滑音（记在音上方），别拿来画上下滑音；SMuFL 的铜管 lift/fall 字形也不是。投影档也画（用户定）。
- **同一谱表的第二声部**（123/ABC 的 `&`、MusicXML 同一 `<staff>` 的第二个 `<voice>`）：分路判据只一份（`crates/model/src/innervoice.rs::lanes_of`：
  主行是 `melodyLane`，同谱表编号次小的 voice 是第二声部，第三路起与别的谱表排不下）。行视图（`dolce-model::view/src/slots.rs::build_row`）把一行里连续几个带第二声部的小节
  并成一个并排块（`InlineLayerElement`，`below: true`），挂在段首；不满小节的补不可见休止（不画减时线），块里小节之间补普通线。
  排法同文本谱 `{dsb…}`，只是上下对调——主行在上、第二声部在下（`place/layers.rs`，`splitRise` 取负）。
  **下行先按自己的节奏排、与主行一起归列**（`place/layers.rs::below_layer_lines` → `place_columns`，`SpacedLine.barBase` = 从主行第几小节起）：
  第二声部的拍位常比主行细（主行八分、下行十六分），只按比例往主行的列里塞会挤成一团（八段锦小钗）。文本谱的 `{dsb}` 两行写法一致，仍按主行的列落。
  MusicXML 的 `<forward>` 空拍在投影时补成不可见休止（`crates/model/src/jianpuproject.rs::fill_voice_gaps`），以前投影直接删 voice > 1。
- **曲首文字与力度互让**（`place/band.rs::lift_texts_over`）：力度、术语贴音落定后，压着的段落词、转调标签整条上提到它之上（全局信息在外、局部信息在内），
  连带被顶到的别的段落词/标签一起推；先落定的记号压上后一组时后一组抬到它之上。
- 乐句排版：行长以小节数计，「放不放得下」由 `dolce-layout/src/layout.rs::measure_document`（门面 `painter.ts::measureDocument`）按当前档的纸与样式量出的真实坐标判（按元素 id，只量带歌词的旋律声部；
  文本谱不清换行、`natural_spans` 逐行接着量）。文本谱与多声部的简谱档不给尺子（一句一行）。

## 已知限制

- 投影档只排第一首（记在 dev 待办）。
- 页脚（BL/BC/BR）分页时贴在本曲末页的页底（用户定 2026-10-21，`compose/footer.rs::layout_footers`）；谱排到太低放不下时退回跟在最低一行之下，
  分页时没有为它预留空间。连续长图跟在本曲最低一行之下。
- 混合拍的说明文字（`Song.timeNote`）只在源格式之间往返，页眉不画。

具体曲目的未修版面问题记在本地私有仓库的待办（不入库）。
