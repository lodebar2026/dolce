# 可视化编辑（`editor/visual/`）

**判据全录** → [../实现/可视化编辑.md](../实现/可视化编辑.md)（点选身份、五线谱档、MusicXML 模型编辑、小节操作）；其余判据在本页

## 职责

在谱面上直接选中、插入、修改音符与记号；操作说明在帮助的「可视化编辑」页（快捷键表由动作表生成）。
地基是[编辑器](编辑器.md)的**双向定位**（`editor/sync.ts`）：选中什么、改哪一段原文，一律按 `SyncEntry` 认。

## 入口

| 文件 | 作用 |
|---|---|
| `keys.ts` | **动作表**：快捷键、名字、说明只写这一份；键盘、帮助、右键菜单、记号面板都从它取 |
| `controller.ts` | `VisualEditController`：谱面焦点下的键盘、点击、右键；经宿主接口 `VisualHost` 向 App 要能力 |
| `cursor.ts` / `overlay.ts` | 两种光标在代码区 / 谱面的画法；换行符号、拍数不对的小节标红（叠加层，不重排版） |
| `ops.ts` / `breaks.ts` | 动作 → 对原文的局部补丁（与格式无关）；换行增删连带拆并歌词行 |
| `dialect.ts` + `dialects/` | **因格式而异的全在这里**（`FormatAdapter.editDialect`）：123、ABC、`.jpwabc`、文本谱各一份 |
| `menu.ts` / `preview.ts` | 右键菜单与记号面板；按键即发声 |
| `selinfo.ts` | 选中元素的读数（声部、小节、拍、音名唱名、时值），排版区标题栏显示 |
| `measureops.ts` / `measureinput.ts` | 文本格式的小节操作（按方言的「小节写法表」`EditDialect.measure` 补原文）；调号 / 拍号 / 速度输入怎么读 |
| `modelops.ts` / `inline.ts` | `.musicxml` 的模型那一路（见下）；谱面内联输入框（改字、问调号拍号速度） |
| `moves.ts` | 挪动的文本那一路：歌词挪格（`w:` 行插删跳格符）、挂在音前的记号搬到相邻的音、弧的括号挪位 |

## 关键判据

- **源码仍是真身**：每个动作落成对代码区原文的局部补丁（`userEvent: "input.visual"`），不走「改模型再整份重出」
  （那样会丢注释与手写排版）。撤销重做就是代码区那份 history；补丁后立即重排（`reloadNow`），不等 200ms 防抖。
- **光标状态只存一份**：代码区选区。非空 = 编辑模式（方块），空 = 插入模式（竖线）；谱面光标由它推出，两侧不会不同步。
  谱面上的竖线与方块只在谱面有焦点时画（没点过谱面不亮光标；双击改字时焦点在代码区，字里的光标照画，且与音符间的光标同粗、照闪：`vis-caret-live`）。
  竖线高度：五线谱 / 识别核对取谱表带或识别行，简谱取本行音符数字的字框（`controller.ts::digitBand`），在一行音符里走高度不变。
  代码区有焦点时原生选区就是这两种样子；谱面有焦点时代码区另画（`cursor.ts`）。**没有第三种状态**——
  文字的「选中」与「编辑」之分靠**焦点在谱面还是在代码区**（`document.activeElement === scorePane`），不另立状态机。
- **选中音符只罩音头**（升降号、唱名、八度点），不带减时线、附点、增时线与 `.jpwabc` token 里的括号（`EditDialect.noteParts`）；
  动作认音符按「选区碰到的」，所以只罩音头照样能改整个 token。
- **文字是单击选中、双击才编辑**（Sibelius 那一路的手感）：单击歌词字或页眉字段（标题/副标题/署名/调号拍号）
  只选中它整段原文、焦点留在谱面（此时 `Delete` / `Backspace` 删掉这段文字）；双击才进插入模式——
  光标落在原文里点中的那个字前后（`getExtentOfChar` 按字的中线分，画出来的字与原文按包含关系对位：署名会补「作词：」、`{三四}` 画出来不带括号），
  焦点交给代码区，接着打字就是改原文（谱面焦点下数字键是插音符，不能留在谱面上）。
  改字时的 `Enter` / `Shift+Enter` 由代码区一条最高优先级键位接住（`app.ts` → `textEnter`）：歌词里在光标那个字的音处换行 / 换页
  （光标在字前 = 这个音之前），走与谱面回车同一条路按格式改原文、焦点回谱面；页眉字段里只结束改字、回谱面选中它。只在**双击进来的改字会话**里接（`textEditing`：双击置上，在代码区按下鼠标、焦点离开代码区即清），
  直接在代码区打字时 Enter 照常插换行。
  双击靠浏览器原生的 `click` ×2 + `dblclick` 顺序：第一下已经选中，`dblclick` 再覆盖成插入光标，**不自己做点击计时**。
- **歌词一次只选一段里的一个字**：展开档的音符格把各段歌词收在同一个 `<g>` 里，点选按段号（`Lyric.verse` ↔ `SyncEntry.verseNo`）取那一段自己的字；
  **和弦名**同样单击选中整个记号、双击进改字（字里的光标只在改字会话里画，平时光标停在它两端是在音符之间）；改字时 Enter 回谱面选中它。
  简谱排版里和弦组打 `harmony` 标签按音符格认；长音中途换的（挂在增时线上）不在音符格里，标签带增时线的 id，索引条目记 `own`。
  识别核对视图里源图和弦框按原识别对回「第几个音的哪个落点」（`reproject.ts::chordSlots`，字相同、横向最近、在所属谱行上方；
  落点是音符本身 / 第几条增时线，与建模同一份 `todoc.ts::chordPlacesOf`——按「第几个和弦」数的话删掉前一个后面的就错位），
  命中层带 `data-kind=chord`、`data-slot` 记落点；改过的按现在的字标蓝重画、删掉的划灰（`chordFixes`）；
  核对时新加的（源图上没有框）按宿主音插值出位置画在谱行上方、标蓝，命中框带 `data-id`（`chordAdds`）。回归 `recognize-edit-check`。
  点亮音符只亮音符本身：格里的和弦名不上光标色（`styles.css` 跳过不带 `cursor-at` 的 `g.vis-chord`；简谱 SVG 不写类名，这个类由 `SyncView.bindEls`（`editor/syncview.ts`） 绑定时标上），方块也不罩它（`musicBox` 跳过和弦组）。`.jpwabc` 的 `.Words` 逐字记原文位置（`WordsItem.source` → 模型 `Lyric.source`），所以也能单点一个字。
- **页眉字段**：模型不记原文位置，按格式从原文认（`EditDialect.headerFields`，`visual/header.ts`：123/ABC 的 `T:`/`C:`/`K:`/`M:`，
  文本谱的 `T:`/`Z:`/`1=C4/4`…，`.jpwabc` 的 `.Title` 段），并进索引（`SyncIndex.addHeader`，条目 `header`）；
  谱面上两个排版器把页眉文字标 `hdr`、调号 `hdr-keysig`、拍号 `hdr-time`（`headerPartsOf`），文字按字对、调号拍号按角色对（`App._bindHeader`）。
- 选中色只有一种（蓝）：光标所在、点选、编辑方块、代码区选区与光标同色；拍数不对的红框要接 hover 说明，点击透过它落到音符上（`hitThroughOverlay`），
  且与上次一样时不重画（焦点一进谱面就会重画叠加层，换掉按下时点中的节点会丢掉这一下点击）。
- 动作之前先看索引是否按当前原文建的（`syncFresh`）：刚撤销、刚在代码区打过字、重排还在防抖里时先重排，否则会按旧偏移改错地方。
- token 读不懂（夹着别的东西，如文本谱 `5&rit/`）就拒绝并说明，不硬改。
- `/` 不绑定：谱面上不用它，歌词录入框里是「这个音不填」。
- **歌词录入**（`lyrics.ts`，`Ctrl/⌘+L`、网页版 `Alt+L`）：内联框带一组提交键（`InlineOptions.keys`：空格、`-`、`_`、`/`、`Shift+空格`、Enter），
  输入法组字时（`isComposing` / keyCode 229）一律放给输入法。123 / ABC 按对位格写 `w:`（`breaks.ts` 同一套格数：`slotsBetween` 数音、`parseLyricLine` 的 `starts` 数词），
  不够格补跳格符（123 `/`、ABC `*`），没词行新起一行；文本谱、`.jpwabc` 只改已有字的格。MusicXML `setLyric` 按前一个字推 `syllabic`。
  跳到下一个音按「第几个可配字的音」认（写完重排后 id 会变），休止不算；连打几个汉字一字一音往后分。
- **改音高的键位对齐打谱软件**：`↑↓` 调内音级（Sibelius）、`Alt+↑↓` 半音（Dorico）、`'` `,` 与 `Ctrl/⌘+↑↓` 八度、`A`–`G` 音名（MuseScore），
  降号 `Shift+B`、延长号 `Shift+F`（字母让给音名）。文本那一路全在唱名上算（`ops.ts::stepDegree/stepSemitone/setLetter/insertLetter`；
  各格式的 `NoteToken` 升降号都已是相对调号的，ABC 也是），模型那一路同名函数在 `model/edit.ts`（半音按调号拼写 `spellMidi`）。
  音名 → 唱名：主音音名 = 升号数 ×4 格（五度）；编辑模式八度取离原音最近（改错音名不跳八度），插入模式取离前一个音最近。
  插入模式下改音高的几样作用于光标前那个音、光标不动（MuseScore 输入态）。
- 简谱两档与五线谱/混排档都启用；文本格式改原文，`.musicxml` 改模型（下面两节）。识别核对另说。
- **和弦名录入**（`Ctrl/⌘+K`、网页版 `Alt+K`）：文本那一路走 `EditDialect.chordText`（123 合规不带引号、后面跟空格，ABC 引号形），
  有就换（换成带引号的、后面原有空白就不再补）、没有就写在这个音所有前置记号的最前面；MusicXML `setHarmony` 只记原文，写出端按文字解析结构。
- **文字 / 力度**（`Ctrl/⌘+T` / `Ctrl/⌘+E`，网页版 Alt）：`EditDialect.annotationText` / `dynamicText`（123、ABC 的 `"^…"`、`!mf!`）；
  123 / ABC 读 `!mf!` 是名叫 `mf` 的装饰（`markKind: "deco"`），所以认现成力度按名字（`ops.ts::DYNAMICS`）。MusicXML 在小节里挂 `<direction>`（`afterElements` = 这个音前面的元素数）。
- **连音**（`Ctrl/⌘+3`，网页版 `Alt+Shift+3`——`Alt+3` 已是加和弦音、`Ctrl+3` 浏览器切标签）：`EditDialect.tuplet`（123 `(n: … )`、ABC `(n` 按个数收）；
  组前已有连音头（123 还要组后紧跟 `)`）就拆。MusicXML `toggleTuplet`：同小节同声线，时值乘 `normal/n`（`fitDivisions` 必要时放大单位）、记 `timeMod` 与 `tuplet` 记号；比例表同 123（`tupletNormal`）。
- **切档**：选区就是代码区选区，跨档本来就在（方块光标照画）；起播点没点过音时取选区第一个音。记号面板在五线谱 / 混排档把时值按钮换成音符（`menu.ts::STAFF_SHORT`）。
- **剪贴板**（`clipboard.ts`）：原文那段 + 与格式无关的 `ClipItem`（唱名、八度、相对升降号、减时线、附点；增时线、小节线）两份一起记。
  同一种格式（方言对象相同）原样贴原文，别的格式与 MusicXML 按 `ClipItem` 重写（按唱名走，换调不换唱名；MusicXML 的小节线不贴、增时线并成多一拍）。
  键盘的 `Ctrl/⌘+C/X/V` 不在 keydown 里做，放给浏览器的 `copy`/`cut`/`paste` 事件——那里不要剪贴板权限就拿得到系统剪贴板的字（桌面外壳一样）；
  系统剪贴板里的字与上次复制的不同 = 外面拷来的，当这种格式的原文贴。编辑模式贴在选区后面不覆盖（简谱没有固定小节格子，覆盖会挤乱后面的拍）。
- **移调**（`transpose.ts`）：全曲 = 每处调号换主音（主音写法与 `transposeFifths` 同一张表，小调取与关系大调同号的写法，D♯m 不写 E♭m），
  再把每个音按「旧调号读、新调号写」重印一遍——简谱各格式印出来不变，ABC 的绝对音名就移过去了。ABC 家族认行首 `K:` 与行内 `[K:…]`，
  文本谱、`.jpwabc` 只认页眉那处。选区 = `shiftSemitones`（拼写同 `Alt+↑↓`）；移上去再移回来，调内音逐字还原，半音位置的音音高还原、拼法按调号与方向重定（C 调 `#4` 升小三度再降回成 `b5`）。MusicXML 在模型上移音并换每处 `<key>`（`transposeScore`）；和弦记号都不动。
- **识别修正的几样动作**（对照主要识谱软件 PhotoScore、SmartScore、ScanScore、Audiveris 定的手感，回归口径的「手动操作」一样对一个动作，见私有仓库 `docs/识别手动操作.md`）：
  - **重读**：改谱号 / 改调号有「重读音高」一种——符头位置不动，所有音按新谱号、没印临时记号的音按新调号重读（`model/edit.ts::setClefAt(reread)` / `rereadKeyAt`；
    印出来的临时记号是谱面上的，重读**不重算印法**，否则提醒记号被当成多余的去掉）。识谱软件改谱号调号是纠正认错，打谱软件是保音高，两种都给。
    简谱的调号只是 `1=` 一处，改它本来就是重读。
  - **挪动**（`Alt+←/→` 整个挪、`Shift+Alt+←/→` 只挪终点、`Ctrl/⌘+Alt+←/→` 按小节）：力度 / 文字 / 速度 / 渐强渐弱（MusicXML 的 `<direction>`）挪到相邻的音前，
    和弦名挪到相邻的音，弧挪端点；**歌词字挪格**按「在这个字前空一格、后面紧接的字顺次推到第一个空格」——回归口径里「一串字错开同样几个音是一步」就是它；
    选中了几个字只挪这几个、选一个字也一样（打谱软件的方向键都只动选中的东西；不这样，往后挪吸收掉空格的那串会与后面的字连成一串，往回挪会多带，选一个字往后挪再往回就收不回原样）。不越过另一端、延音线不挪（只连相邻同音）。
  - **拖动**：只在**已选中**的挂件上按下才拖（从空白按下仍是框选、在没选中的东西上按下仍是点选），拖动中最近的音描框拉虚线，松手按「隔几个能挂的音」走同一个挪动动作（一步撤销）。
    按在选中项的屏幕框里（略放宽）就算按中它：弧是细线不好按准、与别的记号叠在一起时也以选中的为准；弧按在右半边拖终点、左半边拖起点（短弧两头的音挨得近，按离哪个音近判会判反）。
    拖动的监听先于框选挂、接走时 `stopImmediatePropagation`。
  - **补 / 删一层符杠**：`Shift+G` 选中整组连杠的音（`beamGroupOf`；原文没写 `<beam>` 的按 `rebeam` 同一口径划），再 `_` / `=` 整组减半 / 加倍。
  - **`F8` / `Shift+F8`**：拍数不对的小节与识别核对的可疑项并成一张按原文位置排的表，从选区往后 / 往前找；红框角上标差额（`beatTag`）。
  - **Alt+点原图空白**（识别核对）：补漏识的音或小节线，见 [识别-五线谱位图](识别-五线谱位图.md)「编辑器接入」。
- **双击小节空白选整小节、从空白拖动框选**：单击空白仍是落插入光标（`caretAtPoint`），所以选小节放在双击上
  （第一下 click 落光标，`dblclick` 覆盖成选区，与文字双击同一机制）；框选只在**鼠标从空白处**按下、移过 4px 才开，
  松开后浏览器补发的那一下 click 要吞掉（`swallowClick`），否则框出的选区又被换成插入光标。触屏不开（拖动是平移）。
- **试听播放 / 暂停中点音符让给播放**：点中音符（音头、歌词、增时线）只跳到那儿接着播，不进点选（`App._seekByPick` / `_onSyncClick`）。
  否则点击先被点选接走，时间不动、音符反倒被选中；停止状态下照常点选。

## 分篇（判据全录在实现篇）

- 音符之外能单独点选的五样（增时线两种、小节线、弧、减时线）各有各的身份与认法，下次再加一样照表对号入座 → [实现篇](../实现/可视化编辑.md)「点得中自己」。
- 五线谱 / 混排档：索引与谱面分两步建（谱面异步）、歌词弧小节线标题挂身份标签（与简谱同一套，SVG 不变）、框按墨迹量、光标取谱表带、几何命中只在简谱路 → [实现篇](../实现/可视化编辑.md)「五线谱 / 混排档」。
- `.musicxml` 改模型再整份重写：索引按 DOM 文档序对到隐藏代码区的 XML 原文、按位置落选区、结构改动后整曲转自动铺排、时值单位太粗自动放大、内联改字 → [实现篇](../实现/可视化编辑.md)「MusicXML：改模型」。
- 小节操作：文本格式按方言的小节写法表补原文（小节前紧挨的一串小节线当一组），`.musicxml` 所有声部一起改 → [实现篇](../实现/可视化编辑.md)「小节操作」。
- **ABC / 123 借道改模型**（`controller.ts::BRIDGED`，issue 23 源码问题 P4）：谱号（含重读）、渐强渐弱、倚音互转、奏法装饰、和弦加音、换声部，
  在 ABC / 123 里把原文读成 MusicXML 形状的模型（`App.bridgeModel`：投影、元素 id 不变、123 的唱名去掉）照 `.musicxml` 那一路改，
  再按改过的音高重推唱名、整份写回这种格式（`bridgeWrite`，只把前后不同的一段放进代码区）。原文不是标准写法（有注释、手排的换行空格）时每份谱先问一次。
  大谱表（`V:2 part=1`）的加删小节、`|` 拆小节、删小节线并小节、换调号拍号也借道，两条谱表一起改。八度线 ABC / 123 没有写法，只给 `.musicxml`。

## 各格式的要点

- **123**：`$` 结束一行曲，其后的 `w:` 只挂最后一行曲——插换行要把代码行拆开、每条 `w:` 按对位格数（`parseLyricLine` 的 `starts`）拆两半；删换行反过来接上，前一行词不够长用 `/` 补格。`+:` 续行拆不清，拒绝。
- **ABC**：音名 ↔ 唱名按调号换算（八度口径同 `degreeFromPitch`），时值相对 `L:`，升降号是绝对的（ABC §4.2），动作层的相对调号，按这个位置的调号折算（`K:F` 里对 4 按升号写 `=B`、按还原号写 `_B`），延音线写 `-`，换行就是代码行末（`w:` 对紧挨在前的代码行）。
- **`.jpwabc`**：增时线与弧括号在音符 token 里；`-` 不能与 `_`、`.` 连写（`validate` 挡住）；歌词按 `@小节,音符` 锚定（只按小节线数小节，`$` 不算），所以改完按「锚住的音符在原文的位置 → 映射到新原文 → 重数坐标」重算锚点（`postEdit`，与改动并成一步撤销）。
- **虚拟换行**：ABC/`.jcx` 的代码行末、文本谱另起的 `Q:` 在原文里没有符号，索引里没有 `break` 条目（`BreakMark.span === null`），
  位置按挂换行那个音所在代码行的行末算（`virtualBreaks`）。方向键在它两边的元素之间先停在它上面（ABC 选中那个 `\n`、文本谱记 `pickedBreak`），
  插入光标贴着它（行首退格、行末 Delete）删的是换行而不是隔壁的小节线 / 音符。「贴着」按光标所在的**声线**判（`virtualBreakBeside`）：
  多声部时换行符只挂第一声部，第二声部那一行的行首、行末也算；同一声线的前后邻居靠 `voiceOrdinal`（第几首·声部·声线 + 第几个元素）找，原文顺序的邻居可能是别的声部。
  插入这种换行后光标落在新行第一个音前（文本谱重切行后元素 id 会变，也按 `voiceOrdinal` 对回；小节末换行时小节线留在上一行），紧接着退格就撤掉。
- **文本谱**：升降号后置、八度点按方言（番茄 `'` `,`、诗歌本 `g` `d`）；换行不是符号，增删换行 = 照现有行结构加减一刀，复用乐句重排的原文搬运重切 `Q:`/`C:` 行（`jianpu/phrase.ts::fanqieLinesEdited`、`fanqie/relayout.ts::relayoutFanqieBreak`）；弧的 `)` 按队列配对，不许嵌套交叠。

## 小节时值自检（`model/beatcheck.ts`）

逐小节按拍号查时值（四分音符 = 1 拍，按 `divisions` 算——`<type>` 不含增时线），
曲中转拍号认 `attrs.time` 与文本谱记在小节线上的临时拍号（`Barline.time`，右线自下一小节起、左线管本小节）；混合拍（`Song.extraTimes` / 识别的 `meters`）对上任一即过，转过拍的小节按当前拍号也算（识别的页眉拍号压不过曲中转拍号，选本 376）；放过弱起首小节、首尾相加一小节（两头拍号不同时对上哪一头都算：3/4 的弱起 + 转 4/4 后的末小节）、相邻两个不满相加一小节（反复记号劈开的）、
MusicXML 的 `implicit`；无拍号不查。临时多声部各分支要与主分支等长；MusicXML 来源只查**比主声部长**的分支——
副声部可以提前收尾（合唱谱女低、男低唱半小节就并回主声部的和弦），末尾的 `<forward>` 读进来不留元素，短了不算错。**弱起由调用方认**（`opts.pickup`）：识别一律认；编辑器只认**打开时**首小节就不满的声部
（`VisualEditController.documentLoaded` 后第一次查时定下），改谱把原本满的首小节删短了照样报。
**空小节另从原文认**：删掉占满一小节的音（`5 - - -`、`5---`）原文剩 `| |`，解析时空小节不成小节、自检看不见，
编辑器按「同一曲谱行里两条小节线之间只有空白」认出来一并标红、计数，点计数把插入光标放进去。
每次重排都重查（谱面上改、代码区里打字都算）。编辑器标红 + 代码区波浪线；简谱识别完在核对视图按源图坐标标出（`omr/beats.ts`），
私有仓库的 `beat-check.mjs` 也经 CLI 调同一份。
