# 现状与待办（位图五线谱识别）

> [位图五线谱识别](../位图五线谱识别.md)的分篇。只记**做了一半**的事和接着做要知道的上下文；
> 已定的判据、读数口径、试过撤掉的路都在各分篇。

## 独唱谱其余

**当前读数**（45 首 GT，规范展开口径）：音符 97.77%、时值 97.18%、弧线 95.32%，小节数、调号、拍号全对 45/45。
这是位图五线谱独唱谱读数的**唯一记录处**，别处只链接到这里。

判据与试过撤掉的做法见[简谱混排与独唱谱补认](简谱混排与独唱谱补认.md)；逐首定位小节切错用
`staff-measure-all.mjs --bars`（见[度量与跨系统连接](度量与跨系统连接.md)「排查一处错」）。

**按视觉病因排查用 `staff-visual.mjs`**（`--list` 逐条，`--kind=符尾` 只列一类；给人裁定的图文版用 `staff-visual-report/update.py` 刷新，编号与批注跨版保留）。
配对口径：
- 小节按小节线序号对（切分先不管），小节内按音名 + 八度对音；每条带页码与头盒（原图像素）、头空实 / 干 / 尾杠细节、两侧谱号·调号·拍号。
- 识别侧同一时刻按和弦归并（x 离时刻起点 1.5 格内、同一时刻再来同干向的和弦就另起），密排八分不串成一个时刻；
  休止离某个音的时刻起点半格内才并进那个时刻，否则自成一个，全休止排在小节最前。
- 音按**头心**归小节（头盒左缘贴着小节线时按左缘会落进前一小节）。
- 小节内按音名配对时同音名优先配同时值的（一小节里 C5 二分 + C5 四分、只认出四分，报「漏音」而不是「空心读成实心」）。
- 漏音行带位置（本小节识别音的范围，整小节空着给前后挨着的音），裁图直接用。

**先疑 GT**：病因对不上图时先裁图核 GT；报告里「GT 缺」的条目也要先看识别侧是不是**同一个头出了两份**。
**报告的红框框的是「本小节识别到的音」**，漏音那条的真位置不在框里——动手前按 GT 小节内容在图上重新找那个音。
**底本与 musicxml 要同步**：订 GT 一律改底本再 `staff-gt-text.mjs` 重生成，并比一下重生成的 xml 与库里的只差这次的改动。

### 查了没修的

- **人工抄录的 GT 有的没记弧**：44 首里 15 首全曲 0 条（你的信实广大、赞美一神、救主降生……，有的原图确实没有弧）、另有几首只记了一两条
  （高举主大能 1 条，原图第 5 小节女低 D4→C4 就印着一条）。识别多认出的真弧在漏标的曲子上算成错，弧线档的升降要先对图看是不是 GT 漏标。
- **压在谱线上的虚线延音线**（Holy, Holy, Holy m10 女高 A4→A4）：短划被谱线认走，成不了串。
- **两个声部的虚线弧上下叠着**（同曲 m3 男高 G3→A3 与男低 G2→G2）：上面那条离男低的头更近，判成男低下方，两条挂到同一对音上。

- **细干穿过斜空心头被切成两块**（圣哉三一歌伴奏 m3/m14、称谢歌伴奏 m3，同一套字形）：右下粗的那块收成实心头，C5 二分读成 B4 四分。
- **「8」字空心叠头**（所信有根基低音谱表上方 C4 骑加线 + A3 骑顶线三处、我一生要赞美你 m8）：厚圈、内腔一道斜缝，加线上模板分只 0.26（门槛 0.35），
  「头 + 干」那一路把中间收成实心头、上面那个头的圈当成符尾。仍是「这套字形的空心头模板」那个老问题。
- **加线上的斜缝空心头从零认不出**（耶和华 m11 A3，一头上下两干）：模板只打 0.06，斜缝被加线切成两截；要换判据。
- **干端冒出头下半格的「头 + 干」块**（齐来称颂 m11 A2，共干）：块高 1.53 格不到 1.6 的下限、干尖被当符尾自由端；
  放宽下限与 `FLAG_BOTH_ENDS` 各伤合唱谱、只救两个音，撤了。
- **二分头的干贴着小节线**（我一生要赞美你 m34 C5，还连着延音弧）：整块被当小节线认走。
- **空实叠头**（晨曦破晓 m5 F4 实心贴在 A4 空心下）：空心头中心离实心头那根干的端点也在 1.2 格内，`probeBareStems` 当它「端头已挂头」。
- **弯回头部的八分符尾**（主我敬拜你 m15 B♭4，尾弯回贴头围成闭环）：试过专门判据只救一个音，没再做。
- **骑线的八分休止被去线切成两三段**（有一位神 m5、信心使我得胜 m18 两声部共用的那枚）：球与斜笔之间隔着被去掉的谱线，
  有时还有一道一像素宽、去线时顺带剔掉的竖缝；回填只拿到球，整体又只有 1.6 格高（形状下限 1.7）。
