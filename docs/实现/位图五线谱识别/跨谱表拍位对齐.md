# 跨谱表拍位对齐（同系统各行互证改时值、删假头、补漏音）

> 代码：`src/rasteromr/crossalign.ts::fixByCrossStaff`，在 `recognize.ts` 音符阶段 `findTuplets` 之后调；只改时值、删音，
> 起点与声部留给后面的 `checkBars` 重算。矢量路不走这一步。调试：env `XADBG=1` 逐系统逐小节打出各行状态、槽与结论（`XADBG=cols` 再逐列打时值与起点），`XAOFF=1` 关掉整步（对照用）。

合唱谱一个系统里，各行同一拍的音落在同一个 x 上。原先凑拍（`checkBars`）是逐行各凑各的：别的行的拍位只在 `byAnchor`
那一趟、而且前几趟都失败后才借；`pending` 补凑又只给有跨谱表借写的小节（钢琴），因为合唱谱单行在扫描件上认错了音时，
借别的行的拍位能把错的读法也「凑满」（破碎扫描 m61、m80）。这一步把这条约束反过来用：**拿凑满的行验别的行**。

## 拍位槽

- **x 取什么**：和弦**正常一侧**那列符头的中心（干朝上的头在干左、朝下的在干右，二度错开到另一侧的不算；无干的取平均），
  减掉本行本小节左线——各行小节线同 x，减掉以后谱面轻微倾斜也不碍事。
- **时间列**：同 `checkFull`（与上一列首和弦横向不相交就开新列，两根干挨得不到半格仍算一列）。
- **聚槽**：先按窄容差 0.6 格**全连接**聚类——一列要与槽里**每一个**成员都够近，同一行在一个槽里只能有一列；
  再把相邻两个行集不相交、两两都在 1.1 格以内、已知起点不冲突的槽合起来（带临时记号、二度错开的头会把一列推开小半格）。
- **倚音不进槽**：`grace` 的、单音而头高不到本页中位数七成的（`checkFull` 的 `ignoreSmall` 同一尺子）先剔掉，
  不当拍位、不算满拍；一行有倚音别的行没有是常态，不算对不上。

## 满拍互证：谁是锚

每行本小节**自己凑满了**（`BarCheck.full`、不是半截小节、和弦都定了拍位）是锚的候选，候选之间在槽上比起点：

- 一个槽里有两个以上候选、起点不一时，按**过半**定；与多数不一的行、没有过半时所有不一的行，都不可信。
  只有两行凑满、哪里对不上，两行都不可信。
- **满而不齐**的行（自己凑满了，却与锚对不上）不当锚，与凑不满的行一样进下面的纠正——它多半是两处错互相抵掉。
- 锚给槽定起点；槽的起点要随 x 单调，否则整小节不信。
- **提拔**：满而不齐的行，在定了起点的槽上（至少两处）全与锚一致的，也当锚。扫描四首这样的 8 行逐列看过，
  起点全是对的：它们被判不可信只因在没有锚的槽上与另一行凑满却读错的行对不上（只有两行时两行都不信）。
  被提拔的行之间在别的槽上起点不一的都不提拔；提拔后槽的起点不随 x 单调的，撤回。
  当了锚，那个槽有了起点，读错的那一行才改得了（望十架 p10 m75 钢琴右手）。
- 整小节休止、半截小节（`split`）、有跨谱表借写的小节（钢琴）不当锚也不动。

## 时值纠正

一行拆成**声部链**：一个声部的行就一条；两个声部挤一行的（闭合谱女高女低），同一列两个和弦按干朝上/朝下分上下声部
（休止按高低归），一列只一个和弦的是两声部共用一根干，两条链都有它；一列多于两个和弦、或两个和弦干同向的不拆、不动。

先**空跑一遍按干朝向归**（下一段那种）：两声部的行这么归一处都不用改的，整行不动——按共用归会把另一声部的单头算进本声部，
剪短本来对的长音（新编 011 荣归天父歌 m2：上声部 E4 二分、下声部 E4 四分，共用归法把二分剪成四分）。

这样解不出时**再换一种归法试一遍**：有干的单个头只归它干朝向那个声部（另一声部在这里还响着前一个音，或者漏了），
同列另一声部漏掉的音才补得出来（见下「补漏音」）。不一开始就这么归：扫描件上这种头多是同度共用、或同干另一个头漏认，
先这么归改时值那一路反倒解不出（破碎扫描十来处，+14 步）。

还解不出、而行里**无干的长音**（全音符、无干二分）时值和正好一小节的，再换第三种：它们单成一个声部，其余的音另成一个，
另一声部的链头不跟长音同列也从 0 起，补的音干朝向随那一声部的多数。一个声部全小节长音、另一声部走着一串音
（是爱 p5 m69 钢琴左手 F3 全音符 + 一串八分），当一条链永远凑不上；`checkFull` 本来就把自己占满一小节的音放一边，验收不用改。
扫描档这样的行三十来处、新编一百多处，改对的在望十架、破碎扫描（−4 步），新编一首不变。

链上配上了定起点的槽的和弦是**同步点**（链头没配上按 0 算、小节末按拍号长度算）。相邻两个同步点之间那一段的时值和
必须正好等于两点起点之差；配不上槽的和弦，起点要夹在它左右最近两个定了起点的槽之间。一段对不上时：

- **疑三连音**：段长正好是读出时值和的三分之二，整行不动——带方括号的三连音要到挂完歌词才认（`findRasterTuplets`），
  这时还没改时值（爱是从神而来 m7：三个四分 + 二分读成五拍）。只两个音、长的那个不过四分的（四分＋八分占一个四分）不算：
  多是符尾/符杠读错一层，改了七处全对（新编 020、163、178、221、318、386，望十架 p10 m75）；
  二分＋四分占一个二分的照旧不动——两对两错，错的是多出个休止、或两声部共用的头归错（新编 015 称谢歌、187 完全恩爱歌）。
- **易混读法**里找改一处（不行再两处）能对上、而且**只有一种改法**的：二分→四分（实心头印出白斑）、
  四分↔八分↔十六分（符尾多认、漏认一层；只改挂符尾的，接在符杠上的不改层数——杠的逐层状态跟着要改）、
  全音符→二分、无干的二分→全音符。
- **补附点**要原图上真有个点（`stages/structure.ts` 的 `dotProbe`）：头右边、同认附点那一步的窗口里有个点状小墨块
  （长宽 0.15~0.75 格、宽高比 0.5~2、填充四成以上、不压着别的符号）。比认附点那一步松——那一步要点够圆、够孤立、
  不比本页附点小太多，扫描件糊开、贴着符尾的点没收（破碎扫描两处）。原图没有点的段多半是别处错（望十架 p4 一组八分＋十六分差一个十六分，头右边干干净净）。
  补点只在别的读法凑不上时用：不补点也有一种改法的，用那一种（新编 f37 信心加上德行歌：十六分→八分与旁边的头补点并列成两种解）。
  附点只补不删：读出的点在原图上都有墨，删点没有原图证据可验。
- **不验点补附点**（最后一遍兜底）：上面各种归法都解不出、这一行没凑满时，再按共用、按干朝向各试一遍，附点不要原图上有点，
  但只给这种段：**一个音独占两个对齐拍位之间的一段、段长正好是它的一倍半**，而且
  它不带点时该收音的那一拍（别的行在那里起音的槽）**本行谱表上是空的**（`stages/structure.ts` 的 `gapProbe`：拍位左右各 0.9 格、
  谱表上下各伸半格，没有整个落在窗里、长边过半格的墨块；已被认成别的符号的也算墨）；不补音，整行只许改这一处。
  附点被扫描的白条、污渍盖掉时，满拍与别的行的拍位已把它定死（是爱 p1 m10 钢琴左手 F3，点右半落在一道竖向白条上，只剩 3×6 像素）。
  验空挡的是漏认的休止：不验空时破碎扫描 p7 m78 两行、p8 m89、p10 m97 都是四分后漏了八分休止，补点补错；
  已认符号不排除，是因为漏认的休止常被认成临时记号（新编 396 m6、m10 四分休止读成 ♭）；只许改一处挡的是
  陪着别处错改凑数的点（破碎扫描 p3 m33 八分读成四分，两处一起改成「四分→八分、四分→附点四分」）。
- **先别盖住漏音**：头一遍不许拉长的音跨过别的行**全都**起音、本声部却没有音的槽——那里多半漏了音，先走下面的补漏音回原图找
  （新编 264 把八分拉成四分盖住了漏掉的 A4，现在补出来）。三种归法都解不出，第二遍再许盖：这个声部本就持续着的也不少，
  硬不许盖新编 031、315、006、114、279 共 +12，而 086、219、367 那几处确是漏音却在原图上找不着，单看拍位分不开。
  只有部分行起音的、剪短的都不管：开放谱一个声部拖长音别的声部在走是常态（扫描四首硬卡 +20 步），全音符剪成二分本就跨着别的拍。
- 改完 `checkFull` 要凑满、配上槽的列起点正好是槽的起点，**两头都过**才留，否则退回。
- 只有一个锚行时只许改一处：锚自己也可能是错读凑满的。

试过、撤掉的改法：

| 改法 | 为什么撤 |
|---|---|
| 实心四分→空心二分 | 凑不满的段落常是**漏了音**，把前一个四分拉成二分正好补上那段空拍（破碎扫描 p4 m49、p7 m81） |
| 附点补/删（不验点、不限段） | 补错的比补对的多：把八分读成附点八分去凑段长（望十架 p7 m59、p9 m68）；现在要原图验点才补，不验点的只剩上面那种独占一段、验过空的兜底 |
| 有干的二分→全音符 | 有干的不会是全音符；多出的空拍多半是漏音 |
| 单锚不限改几处 | 破碎扫描 p4 m49、p7 m81 单锚改两处都错 |
| 没有锚也按整小节凑 | 那就退回成单行凑满，与跨谱表无关（破碎扫描 p3 m35） |

## 删假头

段内多出来、改读法又凑不上时：段里某个和弦是**弱证据**——没有干、不是休止、所在那列在别的行没有同拍的列（槽里只有它）、
同列没有别的和弦——删掉它以后段长对上、其余各和弦的起点也夹得进界里，而且只有它一个删得，就删
（望十架 p7 m57 D5、p10 m77 C5）。一行只删一个，删了就不再同时改时值。

## 补漏音

段内缺的正好是一个音的时值（含附点）、改读法与删假头都凑不上时：缺口处别的行有个定了起点的槽、本行在那里没有列，
前面的音正好响到那个槽，补进去后后面各和弦的起点也夹得进界里——只有一处补得，才回原图去找（`recognize.ts` 里的 `headSearch`）：

- **先找休止**：槽的 x 横向一格内、谱表上下一格内的墨块，形状字典认成休止的，或者是**方块**（宽 0.9~2.2 格、高 0.3~0.8 格、
  填充八成、在谱表里，`REST_BLOCK_*`；缺的是二分以上才认）——补一个时值等于缺口的休止。扫描档补出来的头有一半落在 GT 记休止的地方
  （破碎扫描 p3 m42、是爱 p3 m38 低音的二分休止贴着第三线，形状字典认不出）。
- **再找头**：缺口二分以上用本页自举的空心模板、以下用实心模板（`buildHollowMasks`/`buildHeadMasks`），横向半格、
  上下两条加线以内逐级打分，取最高。打分用 `scoreAtMasked`（谱线行不计）：`scoreAt` 在两线之间的空白处也能靠模板里带的线拿到分
  （是爱 p3 m38 一度在空白处补出个 A2）。本行左右有音时只在离它们一个八度以内找。
- **阈值**取本页已认出的头在自己位置上的得分：下 10% 分位，且不低于中位数的四分之一（样本少、糊的页下 10% 分位跌到零下，
  085 扬声赞美歌空心头 −0.02，补出个假 E6/D5）。
- **同列补另一声部**：按第二种归法，本声部在那个槽上没有和弦、那一列只有另一声部的头时也补；上声部漏了就在已有的头上方、
  下声部漏了就在下方找（隔开小半格，不把已有的头再认一遍），补出的音干朝向随声部。两条链在同一槽都缺同样长的音，是共用的那一个整个漏了，补一个。
- 造出来的音没有干（声部补的按声部记干朝向），音高按谱号与 `middleStep`，升降事后整页 `calcAlters` 重算；补完 `checkFull` 要凑满、
  起点落在槽上才收进 `notes` 与页。一行只补一个，补了就不再同时改时值、删假头。
