# 跨谱表拍位对齐（同系统各行互证改时值、删假头）

> 代码：`src/rasteromr/crossalign.ts::fixByCrossStaff`，在 `recognize.ts` 音符阶段 `findTuplets` 之后调；只改时值、删音，
> 起点与声部留给后面的 `checkBars` 重算。矢量路不走这一步。调试：env `XADBG=1` 逐系统逐小节打出各行状态、槽与结论，`XAOFF=1` 关掉整步（对照用）。

合唱谱一个系统里，各行同一拍的音落在同一个 x 上。原先凑拍（`checkBars`）是逐行各凑各的：别的行的拍位只在 `byAnchor`
那一趟、而且前几趟都失败后才借；`pending` 补凑又只给有跨谱表借写的小节（钢琴），因为合唱谱单行在扫描件上认错了音时，
借别的行的拍位能把错的读法也「凑满」（破碎扫描 m61、m80）。这一步把这条约束反过来用：**拿凑满的行验别的行**。

## 拍位槽

- **x 取什么**：和弦**正常一侧**那列符头的中心（干朝上的头在干左、朝下的在干右，二度错开到另一侧的不算；无干的取平均），
  减掉本行本小节左线——各行小节线同 x，减掉以后谱面轻微倾斜也不碍事。
- **时间列**：同 `checkFull`（与上一列首和弦横向不相交就开新列，两根干挨得不到半格仍算一列）。
- **聚槽**：先按窄容差 0.6 格**全连接**聚类——一列要与槽里**每一个**成员都够近，同一行在一个槽里只能有一列；
  再把相邻两个行集不相交、两两都在 1.1 格以内、已知起点不冲突的槽合起来（带临时记号、二度错开的头会把一列推开小半格）。
- **倚音不进槽**：`grace` 的、单音而头高不到本页中位数七成的（`checkFull` 的 `ignoreSmall` 同一尺子）先剔掉，
  不当拍位、不算满拍；一行有倚音别的行没有是常态，不算对不上。

## 满拍互证：谁是锚

每行本小节**自己凑满了**（`BarCheck.full`、不是半截小节、和弦都定了拍位）是锚的候选，候选之间在槽上比起点：

- 一个槽里有两个以上候选、起点不一时，按**过半**定；与多数不一的行、没有过半时所有不一的行，都不可信。
  只有两行凑满、哪里对不上，两行都不可信。
- **满而不齐**的行（自己凑满了，却与锚对不上）不当锚，与凑不满的行一样进下面的纠正——它多半是两处错互相抵掉。
- 锚给槽定起点；槽的起点要随 x 单调，否则整小节不信。
- 整小节休止、半截小节（`split`）、有跨谱表借写的小节（钢琴）不当锚也不动。

## 时值纠正

一行拆成**声部链**：一个声部的行就一条；两个声部挤一行的（闭合谱女高女低），同一列两个和弦按干朝上/朝下分上下声部
（休止按高低归），一列只一个和弦的是两声部共用一根干，两条链都有它；一列多于两个和弦、或两个和弦干同向的不拆、不动。

链上配上了定起点的槽的和弦是**同步点**（链头没配上按 0 算、小节末按拍号长度算）。相邻两个同步点之间那一段的时值和
必须正好等于两点起点之差；配不上槽的和弦，起点要夹在它左右最近两个定了起点的槽之间。一段对不上时：

- **疑三连音**：段长正好是读出时值和的三分之二，整行不动——带方括号的三连音要到挂完歌词才认（`findRasterTuplets`），
  这时还没改时值（爱是从神而来 m7：三个四分 + 二分读成五拍）。
- **易混读法**里找改一处（不行再两处）能对上、而且**只有一种改法**的：二分→四分（实心头印出白斑）、
  四分↔八分↔十六分（符尾多认、漏认一层；只改挂符尾的，接在符杠上的不改层数——杠的逐层状态跟着要改）、
  全音符→二分、无干的二分→全音符。
- 改完 `checkFull` 要凑满、配上槽的列起点正好是槽的起点，**两头都过**才留，否则退回。
- 只有一个锚行时只许改一处：锚自己也可能是错读凑满的。

试过、撤掉的改法：

| 改法 | 为什么撤 |
|---|---|
| 实心四分→空心二分 | 凑不满的段落常是**漏了音**，把前一个四分拉成二分正好补上那段空拍（破碎扫描 p4 m49、p7 m81） |
| 附点补/删 | 补错的比补对的多：把八分读成附点八分去凑段长（望十架 p7 m59、p9 m68）；要看原图有没有点才行 |
| 有干的二分→全音符 | 有干的不会是全音符；多出的空拍多半是漏音 |
| 单锚不限改几处 | 破碎扫描 p4 m49、p7 m81 单锚改两处都错 |
| 没有锚也按整小节凑 | 那就退回成单行凑满，与跨谱表无关（破碎扫描 p3 m35） |

## 删假头

段内多出来、改读法又凑不上时：段里某个和弦是**弱证据**——没有干、不是休止、所在那列在别的行没有同拍的列（槽里只有它）、
同列没有别的和弦——删掉它以后段长对上、其余各和弦的起点也夹得进界里，而且只有它一个删得，就删
（望十架 p7 m57 D5、p10 m77 C5）。一行只删一个，删了就不再同时改时值。
