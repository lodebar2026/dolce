# 多行系统的小节线（合唱谱）

> [位图五线谱识别](../位图五线谱识别.md)的分篇。合唱谱一个系统三到七行（人声几行 + 钢琴大谱表），
> 同一系统各行的小节线同 x——这是版式的铁律，下面几条都立在它上面。两行的闭合谱另见[闭合谱四声部](闭合谱四声部.md)「小节线」。

判据都在 `recognize.ts`，按调用次序：`joinThroughBars`（建页之前）→ `inkSystemBarlines` → `tagSystemBarlines` → `findBarlines`
→ `dropLoneBarlines` → `voteSystemBarlines`；小节切分在 `staffomr/page.ts::makeBars`。

## 贯穿上下两行的小节线：断成两截的接回、伸出去的剪掉（`joinThroughBars`）

大谱表的小节线从上一行的顶线一直画到下一行的底线。

- **两行之间断成两截的接回一根**：竖段抽取在两行之间那一截常抽不出来（旁边贴着反复记号的粗线，孤立性过不了），
  剩下的两截各自伸出谱表三四分之一格、又不落在任何一行的外线上，`findBarlines` 当它是符干，这一处的小节线就丢了
  （《爱是从神而来》首行 `|:` 的细线，首系统 3 小节 → 4 小节）。两截各盖满一行谱（两端离外线不过 0.6 格）、同 x、
  中间那一段原图上**每行都有墨**，就是同一根。
- **盖满两行以上谱的竖线，伸出去的那一截剪掉**：小节线上端接着反复房号括线的竖钩（《是爱》p5 钢琴两行「1.」起处，
  竖钩从顶线上方三格起、与小节线同 x 连成一根），上端不落在任何一行的外线上，被当成符干。符干不会把上下两行谱都盖满；
  剪到所盖各行最外的两条线上，就是一根正经的贯穿小节线。

## 只在一行上有、别的行原图上也没有竖墨的，不是小节线（`dropLoneBarlines`）

`findBarlines` 里「别的行同 x 有像样的竖线才留」那一道放得松（别的行那一根挂成符干的也算——扫描件上真小节线断得多，
要求严了成批丢）。钢琴右手和弦的长干正好盖满谱行、左手同处又有一根别的干时照样留下（《是爱》p5 首行钢琴右手多切一刀、
左手没切，两行从此错开一小节）。这里回原图上验：别的每一行在同 x 左右 0.6 格内都找不到一根贯穿谱行的细竖墨
（`makeBarAt` 的 `through` 档：不管上下伸不伸出去，大谱表的小节线本来就连着上下两行），才摘掉。行末那一根不查
（各行右端参差）。摘标记用 `Seg.removeTag`（位图路专用，矢量路没有撤回的场合）。

## 三行以上的系统按行数表决（`voteSystemBarlines`）

低分辨率的合唱扫描件上每行各错各的——这一行漏一根（线断了、被符头压着），那一行多一根（调号降号的竖笔、
贴着小节线的升降号），七行里各行的小节数是 4/4/5/5/5/5/4（烛光颂曲 p2），逐行对不上。把各行的小节线按 x 归簇（0.6 格内）：

- **过半的行都有**的簇，缺的行照簇的中位 x 补一根（不再验墨：别的行已经作了证）；
- **只有不到三分之一的行有**、别的行原图上同处也没有贯穿谱行的细竖墨的簇，摘掉。

两行的系统不走这里（两行各执一词时没有多数，交给验墨的那两道）。

## 头尾的空小节（`staffomr/page.ts::makeBars`）

多行系统里头尾的空条各行一起删（[闭合谱四声部](闭合谱四声部.md)）。两处修正：

- **各行对不齐时只删别的行没有对应小节的那几条**。一行的末尾多出一截零头（终止线到谱线右端的一小段）时各行就对不齐，
  原先对不齐就把空的全删，另一行真的空小节（整小节休止没认出来、别的行同处有音）跟着删掉，那一行少一个小节
  （《是爱》p5 男声行）。也因此《是爱》p1 第二系统行首那个人声整小节休止的小节留住了（4 → 5 小节，与谱面一致）。
- **单行的系统里，右端有小节线收口的空末条是真小节**，空着是里面的音没认出来（数算主恩第二行末小节一个淡印的二分音符），
  与中间的空条一样留着；删的只是最后一根小节线到谱线右端那一截零头。多行系统各行一起空的收口末条照旧删
  （行末预告调号、拍号前那一根线切出来的）。

## 还没解决的

- **烛光颂曲**（200dpi 灰度扫描，线距 10px、线宽 3px）：各行小节数仍有对不齐的（行首六个降号的竖笔在各行同 x，
  验墨那一道拦不住；调号数全了才能按「谱号 + 调号」的宽度把行首那一段的小节线排除掉）。
- **系统线淡得断开的系统**（同曲 p3 七行裂成 5 + 2、p6 四行裂成 2 + 2、p7 裂成 4 + 1 + 1）已解，见下「系统线断成虚线的并回去」。

## 系统线断成虚线的并回去（`bridgeFaintSysLines`）

系统由谱行左端那条竖线（或括号）串起来。扫描件上人声方括号与管风琴大谱表之间那一截细线常断成虚线，抽不成竖段，
一个系统裂成两三个；两组之间隔着歌词，间距比相邻系统之间还大，按间距并不回来（`joinByGap` 只管单行）。
试过「上下两组小节线逐根同 x 就并」：那一页各行小节线自己还没认齐，一处都没触发。

直接在原图上量：相邻两个系统之间，上面那个系统谱行左端一格以内，找墨最满的一列（左右各容一像素），
这一截里有墨的行过五成（`SYS_LINE_INK`）的就是系统线还连着。六首合唱谱实测：真正的系统间隔 0.03~0.34，断开的 0.77~0.99。
两个系统左端差在六格以内时，在两个左端之间整段找（下面那行淡得只剩后半截、左端量短了）；差得更远的是缩进不同的两个系统，
只看上面那行的左端（烛光颂曲 p2 缩进的首系统与下一系统之间，括号的头伸上来，占比 0.52）。
连着的几个系统补一个罩住它们的系统括号对象，`systemGroups` 照常分。接在 `findBarlines` 之后、小节线表决之前。
