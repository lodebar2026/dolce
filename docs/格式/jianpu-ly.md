# jianpu-ly 文本谱（`.jly`）

[jianpu-ly](https://github.com/ssb22/jianpu-ly)（Silas S. Brown，Apache-2.0）是个 Python 预处理器：
吃一份**普通文本**，吐 LilyPond（`.ly`），由 LilyPond 排成带歌词的简谱。Dolce 把这种文本当成
**第六种源格式**读进来编辑（`docFormat = "jly"`），也能从任何非混排档导出它。

## 判据

- **语法只有一个来源**：上游 README（`jianpu-ly --markdown --chinese` 从源码生成的那份）+ `jianpu-ly.py`。
  ⚠ jianpu-db（语料站）的曲谱只是它的**一种方言** —— 多出 `%<文件名>`、`status=`、`source=`、`%--`、
  `subtitle=` 与收尾的 `%END`。**永远不拿语料样本当标准**（曾经照语料抄过 `%END`，是错的）。
- **认哪种文件只看扩展名**：上游没有版本行、没有签名、也没有必需项（`title=` / `4/4` / `1=Bb`
  都只是"词"），所以**不做内容嗅探**。`.jly` 就是 jianpu-ly；`.txt` 仍走文本谱的方言嗅探。
- **上游不看行**：整份输入是「以空格分隔的词」，`L:` / 页头能不能独占一行是排版偏好。
  不过 **Dolce 自己按文件的行排版**，所以写出端会一行写 4 小节（见下「按乐句重排」）。

## 词法一览（本版读得进 / 写得出的）

| 写法 | 含义 | 读 | 写 |
|---|---|:-:|:-:|
| `1`–`7` | 唱名 | ✅ | ✅ |
| `0` | 休止 | ✅ | ✅ |
| `'` `,` | 八度点（`1'` 高八度、`1,` 低八度，可叠） | ✅ | ✅ |
| `#` `b` `n`（含 `##` `bb`） | 升 / 降 / 还原 | ✅ | ✅ |
| `s` `q` `d` `h` | 十六 / 八 / 三十二 / 六十四分（无字母 = 四分） | ✅ | ✅ |
| `1\` `1\\` | 八分 / 十六分（反斜杠写法，必须跟在音高后） | ✅ | ✅ |
| `.` | 附点（`s1.`） | ✅ | ✅ |
| `-` | 增时线（`1 -` 二分、`1 - -` 附点二分、`1 - - -` 全音符） | ✅ | ✅ |
| `\|` | 小节线 | ✅ | ✅ |
| `~` | 延音线（写在两音之间） | ✅ | ✅ |
| `3[ q1 q1 q1 ]` | 连音成组（`n[` … `]`，`[` 后要有空格） | ✅ | ✅ |
| `g[#45] 1` | 前倚音（**组内不能有空格**，否则上游报 `Unrecognised command`）；时值可带字母 `g[d4d5s6]` | ✅ | ✅ |
| `( 2 3 )` | 圆滑线（一字多音，见下） | ✅ | ✅ |
| `\( 2 3 \)` | LilyPond 的**乐句线**（画弧但不吞音节） | ✅ | ✅ |
| `^"文字"` `_"文字"` | 音符上/下方的文字（模型里与 123 的 `"^…"` 同落点：`Chord.sectionWord`） | ✅ | ✅ |
| `\mf` `\p` `\ff` …（力度名取自 `pu/glyph.ts::DYNAMICS`） | 力度记号（适用于之前的音；与 123 的 `!mf!` 同落点） | ✅ | ✅ |
| `\fermata` | 延长记号（适用于之前的音） | ✅ | ✅ |
| `Fine` `DC` `DS` `Segno` `ToCoda` | 跳转记号（裸词；与 123 的 `!fine!` 同落点 —— 小节线上的记号） | ✅ | ✅ |
| `\break` | 强制换系统（LilyPond 指令原样透传）。**源码的换行本身不影响排版**，要换系统得写它 | ✅ | ✅ |
| `\pageBreak` | 强制换页（实测 1 页 → 3 页） | ✅（写进模型；导出到 `.jly` 时会降级成 `\break`，导出到 123 是 `$$`） | ✅ |
| `\bar ".|:"` `\bar ":|."` | LilyPond 小节线（我们写出反复线用的就是它） | ✅ | ✅ |
| `\bar "\|\|"` `\bar "\|."` | 其余小节线样式 / 其余 LilyPond 指令 | ⚠ 只报 / 透传 | ✅ |
| `4/4`（`4/4,8` 弱起） | 拍号 | ✅ | ✅ |
| `4/4,8` 里的弱起音符时值 | 弱起（逗号后那个分母） | ⚠ 只报（拍号本身读得进，弱起长度丢） | — |
| `1=Bb` / `6=F#` | 调号（大调 / 小调） | ✅ | ✅ |
| `chords=c2. g:7 c` | 吉他和弦符号（单独一行，或 `=` 之后换行、空行结束）：token 是 **LilyPond 和弦语法 + 时值**，时值就是一条时间线；**谱面上点音就能改**（`Alt/⌘+K`） | ✅ | ✅ |
| `R4{ 1 2 }` | 小节反复（％）：上游译成 `\repeat percent 4 { … }` = 里面这些小节**共唱 4 遍**。读进来**展开成真实小节**（8 小节），歌词跟着每一遍都复制 | ✅ | ⚠ 展开着写（不印 ％） |
| `R*8` | 多小节休止（读：展开成 8 个真实小节；写：写成 8 个 `0 0 0 0` 小节 —— 模型里没有「N 小节休止」这种字段，音乐一样、只是不压缩着画） | ✅ | ⚠ 不压缩 |
| `R{ … } A{ … }` | 反复跳跃（`R{` = 反复体、`A{` = 第二房；上游自己的生成规则就是 `<repeat forward>`→`R{`、`<repeat backward>`→`}`、`<ending start>`→`A{`） | ✅ | ✅（只能两房） |
| `4=85` | 速度 | ✅ | ✅ |
| `title=` `subtitle=` `composer=` `poet=` `arranger=` `copyright=` `opus=` | 页头 | ✅ | ✅ |
| `L: …` | 拉丁歌词；**每一条 `L:` 行各是一段**（上游各自变成一个 `\new Lyrics` 往下叠） | ✅ | ✅ |
| `H: …` | 汉字歌词：逐字自动分开；`_` 是**连写**（`一_三` = 一个字两个汉字） | ✅ | ✅ |
| `L:` 后换行、分几行写、**空行**结束 | 多行歌词写法（上游 README：「在 `:` 之后换行输入，并以 2 个空行结束」） | ✅ | — |
| `""` | **空位占位**：这个音上这一段没词（上游自己的 MusicXML 导入端就写 `s if s else '""'`） | ✅ | ✅ |
| `_`（拉丁行里独立一个词） | 跳过这个音（上游给 melisma 续音写它） | ✅ | — |
| `\skip 1` | LilyPond 原生的跳过 | ✅ | — |
| `syl- la- bles` | 词内断音节（`syllabic: "begin"`） | ✅ | — |
| `1.` `2.`（行首） | 歌词段号（印在谱上） | ✅ | 多段时写 |
| `NextScore` / `NextPart` | 多乐章 / 多声部 | ✅ | ⚠ 只写第一份 |
| `% 注释` | 注释（含行内） | ✅ | ✅ |
| `{多字}` 之外的空缺 | 其余写法见下「本版不收」 | ⚠ 只报 | — |

## 最容易踩的三个坑（都是拿真工具量出来的）

这一节的每条都有「真 `jianpu-ly` + 真 LilyPond + 读产出 SVG 坐标」的实测支撑，
判据写在 `src/model/tojly.ts` / `fromjly.ts` 的注释里（改之前先读那段注释）。

1. **某一段在这个音上没词，必须写 `""`**。音节是按顺序落到音上的，少一个占位，后面**整行左移一格**。
   实测：`1 2 3 4` 上"缺一格"的谱，7 个音节里 6 个落错音；补上 `""` 后逐个对上。
2. **圆滑线 `( )` 会吞音节**。jianpu-ly 把它译成 LilyPond 圆滑线，而 LilyPond 的
   `melismaBusyProperties` 默认含 `slurMelismaBusy` —— 弧内的音**不吃音节**。
   更阴的是**弧算在哪个音头上看它写在哪儿**：`1 ( 2 3 ) 4` 里 `(` 落在 `1` 后面，LilyPond 当它是
   `1` 的后置事件（弧从 `1` 起、`2` `3` 被吞）；而弧写在一行最前面时算在下一个音头上。
   所以写出端**一律把 `(` 后置**贴在起音的数字后面，并且只在"真的一字多音"（每段在这组里至多一个
   音节、且落在组首）时才写 `(`，其余写乐句线 `\(`（照样画弧、不吞音节）。
3. **拉丁音节一律加引号**。不加引号时 `4`、`s0`、`r`、`1a`、`x2` 这种"看着像时值"的字会被 LilyPond
   当成跳过记号：实测裸 `s0` 直接报 `not a duration`、裸 `4`/`1a`/`x2` 会被吃掉半个字。
   加引号（`"do"`）与裸写法画出来的坐标**逐一相同**，空串 `""` 就是占位。
4. **跳转裸词要写不带点的 `DC` / `DS`**。模型里（和 123 的 `!D.C.!` 里）是带点的 `D.C.` / `D.S.`，
   但写成裸词时上游只认 `DC` / `DS` —— 实测 `D.C.` 会被拒（`Unrecognised command D.C. in score 1`）。
   所以读进来两种都认、写出去一律去点。

## 本版不收的写法（认得出、报得出，不硬读）

**倚音和弦** `g[1&3&5]`（引擎输入里一个倚音只有一个音高）、
`4/4,8` 里的**弱起长度**（拍号本身读得进）、`LP:` / `LPH:`（原样 LilyPond 代码块）、布局开关（`NoBarNums` `NoIndent` `OnePage` `RaggedLast`
`SeparateTimesig` `angka` `WithStaff` `PartMidi` `RepeatAccidentals` `NormalAccidentals`）、
`frets=` / `instrument=`（指板图 / 乐器）、`arpUp` `arpDown` `arp`、二胡符号
（`Fr=` `slide` `souyin` `harmonic` `bend`）、排练记号 / 滑音 / 泛音（`letterA` `glis` `Harm:`）、
基准八度切换 `<>`、`8` `9` 八度快捷键、`x`（打击乐）、其余 `\…` 指令。

跳转裸词按**它所在小节的小节线**收（与 123 的 `!fine!` 同一个落点），所以它写在小节中间时，
位置会挪到该小节线 —— 要精确到元素就得另立字段（现在不做）。

导出时装不下的东西（多声部、多乐章、和弦符号、演奏法、反复跳跃、拉丁歌词的连字符）会**写进 `.jly`
的 `%` 注释里**，随文件走、不静默丢。

## 与其它格式的关系

- **不是「另存为」目标**：导出菜单里单列一项「jianpu-ly」，写出 `.jly`（上游读任何扩展名，但按它自己
  `--export-jly` 的约定写成 `.jly`）。`CONVERT_TARGETS` 里没有它，所以「另存为」列表里也不出现。
- **读回来是一等源格式**：可编辑、可保存，谱面上能改音符 / 时值 / 八度 / 变音 / 记号 / 圆滑线 / 歌词 / 换行
  （见 [可视化编辑](../模块/可视化编辑.md)）；小节操作与和弦名请在源码区改（方言没给 `measure` / `chordText`）。
- **按乐句重排**：`.jly` 的曲行按每 4 小节重新断行，词行、页头、注释一个字不动
  （`fromjly.ts::rewrapJlyText`）。上游不看行，但 Dolce 自己按行排版，一行到底会挤成一团。
- **导出之后怎么用**：`jianpu-ly 曲子.jly > 曲子.ly && lilypond 曲子.ly`。

排版链路与模块分工见 [源格式-jianpu-ly](../模块/源格式-jianpu-ly.md)。
