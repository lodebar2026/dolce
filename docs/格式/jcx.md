# Muse 简谱 `.jcx`

Muse 曲谱软件（Windows）的脚本格式。**ABC 方言**：字段头、小节线、房号、`w:` 歌词、分数时值都同 ABC；
差别在简谱轨里**字母是首调唱名**，以及几处 Muse 自己的写法。本页按官方说明书（§3.2「脚本输入方式」、第 8 章 FAQ）
与官网谱例整理，并写明本项目读写到哪一步。实现见 [源格式-abc家族](../模块/源格式-abc家族.md)。

## 文件与编码

| 首行 | 版本 | 编码 |
|---|---|---|
| `%MUSE2` | Muse 3.1 以前 | 简体版 GBK、繁体版 BIG5 |
| `%MUSE3` | Muse 3.1（2026-08）起 | UTF-8；3.1 以前的 Muse 打开是乱码 |

- 读：BOM → 合法 UTF-8（含 `%MUSE3`）→ GBK 或 BIG5（`common/jcxcodec.ts`）。GBK 解码器把 BIG5 字节也解成「某个字」、不报错，
  所以按字节分布判：双字节字里尾字节落在 0x40–0x7E 的超过 15% 就按 BIG5（谱例 45 首简体 GBK 最高 0.75%，繁体 BIG5 文本约四成）。
- 写：**`%MUSE2` + GBK + CRLF**，新旧版 Muse 都能开；打开的就是 `%MUSE3` 文件则按 UTF-8 存回（整份重写——按乐句重排——也保留 `%MUSE3`）。
  GBK 里没有的字存成 `?`，存盘时在状态栏列出。
- 一个文件一首，没有 `X:`。

## 头部

以 `T:` 起、`K:` 收（FAQ：缺了会出错，哪怕写空的 `T:`），随后是 `V:` 声明。

| 字段 | 含义 | 本项目 |
|---|---|---|
| `T:` | 标题；第二条起是副标题 | 读写 |
| `C:` | 作者，可多条，印在右上 | 读写（`creators`） |
| `I:` | **左上角文字**（不是 ABC 的指令） | 读写（`pageText.topLeft`） |
| `S:` | 来源 | 读写（meta `source`） |
| `M:` `L:` `Q:` | 拍号、默认音长、速度，同 ABC；没写 `L:` 按拍号推 | 读写；写出固定 `L:1/8` |
| `K:` | 调号：`K:F` `K:Eb` `K:Am` `K:A bass`；实际文件里降号写在前（`K: bE`） | 读只取开头的调名与调式；写前置形 `bE` |
| `V:` | `V:<标志> style=jianpu\|staff\|tab\|ukulele name=… ins=… vol=… brk=…` | 见下 |
| `%%…` | Muse 的排版参数（字体、页边、行距…） | 原文另存（`Song.museDirectives`），只写回 `.jcx`，不交本项目的样式层、不写进别的格式；别的格式的版面指令也不写成 `%%`。`%%begintext`…`%%endtext` 文字块读成说明文字，没收尾报诊断 |

`V:` 的标志可以是任意名字；正文里每行（或每段）前写 `[V: <标志>]` 切声部，同一行后面可以接音乐。
`style=jianpu` 读成简谱声部；`style=staff` 的字母是绝对音名（同 ABC），读进来换算成度数；
`tab`、`ukulele` 不读，报诊断。`name`/`nm`、`sname`/`snm` 是声部名（值可加 `"…"` 或 `“…”`），
其余参数（播放乐器、音量、括号…）原文留着，写回时照写。

## 音乐体

| 写法 | 含义 |
|---|---|
| `C D E F G A B` | **简谱轨里是 1–7**（C 恒为 1，与调号无关） |
| 小写 / `'` / `,` | 高八度 / 再高 / 低八度（`c` = `C'`） |
| `^` `_` `=` `^^` `__` | 升、降、还原（相对调号，即简谱的升降号） |
| `2` `/` `//` `3/2` | 时值，相对 `L:` |
| `a>b` `a<b` | 破碎节奏。**短的那个音 = 附点那个音原长的一半**（见下） |
| `z` `Z` | 休止，带时值（`Z` 不是 ABC 的整小节休止） |
| `@` | 不可见休止 |
| `x` `X` | X 音符（有声无音高） |
| `-` | 延音线 |
| `( … )` | 圆滑线 |
| `(3abc` `(p:q:r` | 多连音，同 ABC |
| `{…}` `{@…}` | 倚音、后倚音 |
| `!HOLD!` `!STACC!` `!ATT!` … | 装饰（见下） |
| `(<` … `<)`、`(>` … `>)` | 渐强、渐弱 |
| `"Am"` `"_文字"` | 和弦或音符上方文字、下方文字 |
| `| || |] [| |: :| :: ||: [:] [|]` | 小节线（`[:]` 虚线、`[|]` 隐形线） |
| `|1` `:|2` `[2` | 房号；`"1、3"|0`：房号写 0 时用前面引号里的字 |
| `[K:G]` `[M:3/4]` `[L:1/16]` | 曲中改调、拍号、默认音长（`[L:]` 只管写它的那个声部） |

装饰名与本项目的对应（`model/deconames.ts`）：`HOLD` 延长、`STACC` 顿音、`ATT`/`HAT` 重音、`HUANQI` 换气、
`DANBOYIN` 单波音、`TRILL` 颤音、`SEGNO`/`CODA` 跳转记号。认不出的原样保留、写回。

## 歌词

`w:`（Muse 的谱里 `W:` 也这么用）对应**紧挨在前的那一行**音乐，几条 `w:` 依次是各段。

- 中文逐字一个音，不用空格；英文按空格分词、`-` 分音节。
- `*` 跳过一个音；`~` 把后一个音节并到同一个音，任何音节后面都行（`你~们`、`1.~圣`；英文 `the~Lord` 并成「the Lord」）；
  `样~，` 只是把标点贴在前字上；`\-` 输出「－」。写出时一格里读回会被拆开的地方都插 `~`。
- 休止不配字；连着延音线的两个音各配一个字。

## 本项目的判据

- **代码换行按谱面换行读**（Muse 打开「强制换行」时就按第一音轨的脚本断行排），一行写到底的谱由排版器折行。
  写出按模型里的断行，**按声部分块**：`[V: n]` 一行，随后这个声部的各行音乐、各跟各的 `w:`——
  各声部在 Muse 里的断行不同，按第一声部切系统交错写会把别的声部几行并成一行、几行词并成一条。
- **破碎节奏**：说明书只给了 `a>b` = `a3/2b/2`。谱例里的 `e>G/`、`c2>G/`、`A/>A//` 只有按「短的那个音 = 附点那个音原长的一半」
  才凑得齐整小节（ABC 是短音自己的长度减半）；两音写得一样长时两种算法相同。
- 拍号笔误（`[M:4/4/]`）只取开头的 `n/m`，Muse 自己也照读。
- 多连音默认比例照 ABC 那张表（说明书里的表有笔误）。

## 写不出 / 读不进的

- 写不出：多曲（只写第一首）、样式表、演唱顺序、扩展 meta（只留 `S:`）、纸张、页脚文字、力度、印刷段号、
  休止上的词、换页（退成换行）、长音中间的和弦。另存为时列出（`model/capability.ts`）。
  一字多音的延长写成 `*`（Muse 没有 `_`）。
- 读不进：吉他谱、尤克里里谱音轨；跨行起头的延音线（行首的 `-`）报诊断。
- 谱例里有把三连音写成圆滑线的（`(G GG)`、`(EDC)`，按 `(3` 读才凑齐小节），照圆滑线读，拍数自检会报出来。
- 导出的文件在 Muse 里能否正确打开，目前只按说明书与谱例核对过，没有在 Muse 里实测。
