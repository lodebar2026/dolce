# 需求

> 本项目要做什么、做到什么程度。**做法**见 [架构.md](架构.md)，**各模块细节**见 [模块/](模块/)，
> **阈值与判据**见 [实现/](实现/)。

## 1. 目标

歌谱的**排版**与**播放**，覆盖从数据获取到成品交付的整条链：

- **数据来源多样**：简谱与五线谱，既有文本格式，也有图片与 PDF（需识谱）。
- **曲目规模多样**：单首简单赞美诗，也有四声部合唱谱；单曲，也有整本诗歌集（500 首级）。
- **输出多样**：展开的投影片、单曲的简谱/五线谱/混排谱、整本诗歌集印刷版，以及**多格式对照校对**。
- **特性尽量全**：歌谱特性（反复、房号、多段歌词、和弦、力度、装饰、多声部…）与
  排版特性（断行、分页、装箱、样式定制）都要支持。

## 2. 用户场景

| # | 场景 | 关键需求 |
|---|---|---|
| S1 | 录入/校订一首歌 | 文本编辑即所见，实时重排；点选定位；多源导入 |
| S2 | 做主日投影 | 反复与多段歌词**逐遍展开**，一屏一段；导出矢量 PPTX / PDF |
| S3 | 印一本诗歌集 | 整本装箱分页、目录索引、书级样式统一；一首不跨同一张纸正反面 |
| S4 | 把旧谱数字化 | 图片/PDF 识谱 → 可编辑文本；识别结果要能**按源图叠加核对、在核对视图上直接改**，排版稿里随选随看原图片段 |
| S5 | 校对两个版本 | 同一首歌的多格式（原书 PDF ↔ 识别结果 ↔ 排版产物）逐项对比报表 |
| S6 | 试听确认 | 按谱面速度演奏，竖直播放线跟随各声部起音；可暂停、拖进度条、点音符定位；可调倍速；导出 MIDI |
| S7 | 救低质量排版 | **按乐句重排**：综合歌词标点与音乐信号重新断行 |

## 5. 功能

### 5.1 编辑器

- CodeMirror 6 + 语法高亮，编辑即重排重渲染；点选音符/歌词即高亮（CSS 高亮，不重渲染）
- **可视化编辑**：谱面上直接选中、插入、修改音符与记号（唱名、八度、升降号、时值、增时线、小节线、圆滑线/延音线、延长号、重音、换行换页），
  编辑/插入两种光标在代码区与谱面同步显示，换行符可见可删；快捷键、右键菜单、记号面板三种入口；改动落回原文、与代码区共用撤销。
  四种文本格式（123 / ABC / `.jpwabc` / 文本谱）都支持，展开、原样、五线谱、混排四档都能改；双击小节选整小节、框选、全选，选中元素显示小节/拍/音高/时值读数
- 小节时值自检：拍数与拍号对不上的小节标红（编辑器与图片识谱共用）；改音时按键发声
- **声部面板**（合唱谱）：增删、排序、改名、谱号、按声线 / 按和弦拆分闭合谱、合并、歌词复制；试听静音 / 独奏 / 音量；混排简谱层取哪个声部
- 翻页、双指缩放/平移、简繁转换、设置面板（**只摆当前模式下真正生效的项**）
- **中英双语界面**：按浏览器语言自动选，设置里可切，即时生效；另有英文落地页 `/en/`（见 [编辑器](模块/编辑器.md)「界面语言」）
- 文件 开/存/另存/拖入；`.jpwabc` 读时 BOM 探测、存 UTF-16LE + BOM（兼容 JP-Word）

### 5.2 排版

**四档视图 = 两组正交状态**，不是四个独立视图（详见 [排版-展开与原样两档](模块/排版-展开与原样两档.md)）：

| | 含义 | 用途 |
|---|---|---|
| 展开 | 反复与多段歌词**逐遍展开**，一段一遍谱、逐遍成页 | 投影 |
| 原样 | 按原谱排一遍，多段歌词叠在同一谱行下，反复不展开 | 印刷 |
| 五线谱 | 所有格式都有：`.musicxml` 用原文，文本格式由源文投成 MusicXML | 五线谱软件互通、合唱谱 |
| 混排 | 五线谱叠简谱层 | 简谱读者看五线谱 |

纸张、字号、配色**不属于档位分野**，是独立设置项、两档各记各的。各档由哪个排版器排见 [架构](架构.md) §3.1。

### 5.3 按乐句重排

综合歌词标点、音乐信号（延长号/终止线/长音/休止/连线）与重复旋律结构，在小节边界找乐句断点、
凑成疏密适中的行长（类 Knuth-Plass DP，判据见 [实现/乐句排版](实现/乐句排版.md)）。**断句只经输入接口读谱，与源格式无关**；两个消费者：
文本谱重排**原文本身**（两档一起生效、可一键还原）、成书按元素 id 往排版输入里插换行。

### 5.4 播放

按谱面 `♩=` 速度演奏 × 工具条 ×0.5~×2 倍速，光标跟随；两路音源（浏览器采样音色 / macOS 原生音色）；
试听与导出 MIDI 共用同一速度口径。细节见 [播放](模块/播放.md)。

### 5.5 诗歌集成书

整本装箱（短曲半页起排、一首不跨同一张纸正反面）、目录与索引、页眉页码、注解框、书级样式统一。

## 6. 非功能

| 项 | 要求 |
|---|---|
| 平台 | **Web（免安装）/ macOS / Windows** 同一套前端代码；桌面用 Tauri 2 |
| 离线 | OMR 必须能离线跑（模型随包，不依赖云服务） |
| 体积 | 桌面包尽量小 |
| 一致性 | 「在哪测量就在哪绘制」——排版期度量与渲染同一引擎 |
| 可回归 | 每个模块都要有无头校验脚本与基线，判据写进文档 |
| 语料 | 测试语料与基线只留本地、不入库 |

## 7. 范围外（已放弃，勿重提）

- **IDML 导出**（原 Kotlin 版有，彻底放弃）
- **JAXB / Rust 解析 MusicXML**（改为 TypeScript + DOMParser）
- **引入 ABC 第三方渲染库**（abcjs 等）——渲染全自研，兼容换不到工具链收益
- **扩 `.jpwabc` 语法**（既定决策；新语义走 [123 格式](格式/123格式.md)）
